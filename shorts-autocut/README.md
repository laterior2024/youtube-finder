# ✂️ 쇼츠 자동 편집기 — 1주차: CapCut 프로젝트 파일 열어 보기

이번 주 목표는 딱 하나예요.

> **우리 프로그램이 CapCut 프로젝트 파일을 읽고, 자막을 바꿔서 저장한 뒤, CapCut에서 그 프로젝트가 제대로 열리는지 확인하기.**

이게 되면 나중에 "자동으로 자르고, 자막 넣고, 효과음 넣은 결과"를 CapCut 프로젝트로 저장할 수 있어요.
이게 안 되면 나머지 계획을 바꿔야 해서 맨 먼저 확인하는 거예요.

> ⚠️ 이 도구는 **PC용 CapCut(Windows / Mac)** 전용이에요. 휴대폰 CapCut은 안 돼요.

---

## 준비물

1. **PC용 CapCut** 설치
2. **파이썬 3.9 이상** 설치 ([python.org](https://www.python.org/downloads/))
   - Windows는 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
3. 이 폴더(`shorts-autocut`)를 내 컴퓨터에 받기

따로 설치할 파이썬 패키지는 없어요.

---

## 따라 하기

### 1단계. CapCut에서 "틀" 프로젝트 만들기 (사람이 직접)

1. CapCut을 켜고 **새 프로젝트**를 만들어요.
2. 짧은 영상 하나를 타임라인에 올려요.
3. **자막(텍스트)을 2~3개** 넣어요. 글자는 아무거나 괜찮아요. 폰트, 색, 테두리를 원하는 쇼츠 스타일로 꾸며 두세요. **이 스타일이 그대로 복사돼요.**
4. 가능하면 효과음 하나, 장면 전환 하나도 넣어요. (나중 주차에서 써요)
5. 프로젝트 이름을 **`틀_쇼핑쇼츠`**로 바꾸고 **CapCut을 완전히 꺼요.**
   (켜져 있으면 CapCut이 파일을 다시 덮어쓸 수 있어요.)

### 2단계. 터미널 열기

- **Windows**: `shorts-autocut` 폴더를 열고, 주소창에 `cmd` 입력 후 엔터
- **Mac**: 터미널을 열고 `cd ` (띄어쓰기 포함)를 입력한 뒤 폴더를 끌어다 놓고 엔터

아래 명령에서 `python`이 안 되면 `python3` 또는 `py`로 바꿔 보세요.

### 3단계. 내 CapCut 프로젝트 찾기

```bash
python capcut_draft.py find
```

`틀_쇼핑쇼츠`가 목록에 보이면 성공이에요.

> 목록이 비어 있으면: CapCut → 설정 → **프로젝트 저장 위치**를 확인하고 이렇게 알려 주세요.
> ```bash
> python capcut_draft.py --projects-dir "여기에_폴더_경로" find
> ```
> (`--projects-dir`은 항상 `find`/`inspect` 같은 명령어 **앞에** 써요.)

### 4단계. 프로젝트 들여다보기

```bash
python capcut_draft.py inspect 틀_쇼핑쇼츠
```

이렇게 나오면 성공이에요.

```
📂 프로젝트: 틀_쇼핑쇼츠
   전체 길이: 12.40초   화면 크기: 1080x1920
🎞️  타임라인 줄(tracks)
   1. video 줄 — 조각 1개
   2. text 줄 — 조각 3개
💬 자막 글자
   1. '안녕'
   ...
✅ 읽기 성공! 이 CapCut 버전은 우리 프로그램이 다룰 수 있어요.
```

❌ **"암호화하는 것 같아요"**라고 나오면 아래 [암호화되어 있을 때](#암호화되어-있을-때)를 보세요.

### 5단계. 틀을 복사해서 자막 바꾼 새 프로젝트 만들기

```bash
python capcut_draft.py clone 틀_쇼핑쇼츠 --name 테스트1 --text "이거 미쳤다 ㄷㄷ" --text "채소 3초 컷" --text "링크는 고정댓글"
```

- `--text`를 쓴 순서대로 1번, 2번, 3번 자막이 바뀌어요.
- 폰트, 색, 위치 같은 스타일은 **틀 그대로** 유지돼요.
- 틀 프로젝트는 건드리지 않아요.

### 6단계. CapCut에서 열어 보기 🎉

1. CapCut을 켜요.
2. 프로젝트 목록에 **`테스트1`**이 보이는지 확인해요.
3. 열어서 자막이 바뀌었는지, 영상이 잘 재생되는지 확인해요.

**여기까지 되면 1주차 성공이에요!** ✅

## 잘 안 될 때

### `테스트1`이 목록에 안 보여요
CapCut 버전에 따라 복사한 폴더를 목록에 바로 올리지 않을 수 있어요. 그럴 때는 **그 자리에서 고치는 방식**을 써요.

1. CapCut에서 `틀_쇼핑쇼츠`를 **복제**해요 (프로젝트 카드 `…` → 복제). 이름은 `테스트2`로 해요.
2. CapCut을 완전히 끄고:
   ```bash
   python capcut_draft.py edit 테스트2 --text "이거 미쳤다 ㄷㄷ" --text "채소 3초 컷"
   ```
3. CapCut을 켜서 `테스트2`를 열어요.

원래 파일은 `draft_content.json.backup-날짜` 이름으로 백업돼요. 문제가 생기면 백업 파일 이름을 원래대로 바꾸면 돼요.

### 한 번은 열렸는데, 나갔다가 다시 들어가면 안 열려요
CapCut은 프로젝트를 닫을 때 파일을 다시 저장해요. 이때 복사본의 id가 틀과 맞지 않으면 다음부터 안 열릴 수 있어요.
아래 명령으로 폴더 안을 비교해서 알려 주세요.
```bash
python capcut_draft.py diagnose 테스트1 틀_쇼핑쇼츠
```

### 암호화되어 있을 때
최근 일부 CapCut PC 버전은 프로젝트 파일을 암호화해서 외부 프로그램이 읽을 수 없어요.

1. 지금 쓰는 CapCut 버전을 적어 두세요 (CapCut → 설정 → 정보).
2. 프로젝트 파일이 암호화되지 않는 **예전 버전의 CapCut PC**를 설치하고, **자동 업데이트를 꺼요.**
3. 그 버전에서 1단계부터 다시 해 보세요.
4. 어느 버전에서 됐는지 이 README 맨 아래 "확인된 버전" 표에 적어 두세요.

그래도 안 되면 계획 B로 가요. 앱이 **완성 MP4 + 자막 파일(SRT)**을 만들고, 그걸 CapCut으로 불러와서 손보는 방식이에요.

### 한글이 깨져 보여요
Windows `cmd`에서 먼저 `chcp 65001`을 입력하고 다시 해 보세요.

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `capcut_draft.py` | CapCut 프로젝트 찾기 / 들여다보기 / 복사 / 자막 바꾸기 |
| `test_capcut_draft.py` | 가짜 프로젝트로 위 기능이 맞게 도는지 확인하는 테스트 (`python -m unittest test_capcut_draft.py`) |

### CapCut 프로젝트 파일 구조 (참고)

```
테스트1/
├── draft_content.json    ← 타임라인 전부 (버전에 따라 draft_info.json)
│     ├── materials        재료: videos, audios, texts, transitions ...
│     └── tracks           줄: video / audio / text, 줄마다 segments(조각)
│           └── target_timerange { start, duration }  ← 단위: 마이크로초 (1초 = 1,000,000)
└── draft_meta_info.json  ← 프로젝트 이름, ID, 폴더 위치
```
