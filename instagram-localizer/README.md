# 🌏 인스타 현지화 스튜디오

해외에서 인기 있는 인스타그램 게시물을 **10개 나라** 버전으로 다시 만들어 주는 도구예요.

| 지역 | 나라 (언어) |
|---|---|
| 아시아 | 🇰🇷 한국 · 🇯🇵 일본 · 🇹🇼 대만(중국어 번체) · 🇮🇩 인도네시아 |
| 아메리카 | 🇺🇸 미국(영어) · 🇲🇽 멕시코·중남미(스페인어) · 🇧🇷 브라질(포르투갈어) |
| 유럽 | 🇪🇸 스페인 · 🇩🇪 독일 · 🇫🇷 프랑스 |

나라 버튼 아래에 💰(수익에 유리) / 👀(조회수에 유리) 표시가 있어요. 나라를 많이 고를수록 AI 비용과 시간이 늘어나요.

원본 이미지를 올리고 버튼을 한 번 누르면, 아래 순서로 알아서 진행돼요.

1. **분석**: AI가 이미지 속 글자, 폰트 느낌, 글자 크기·색, 배경, 배치, 그리고 **왜 떡상했는지**를 분석해요.
2. **현지화**: 이미지 속 글자를 그대로 번역하지 않고, 그 나라 크리에이터가 쓴 것처럼 자연스럽게 다시 써요. 첫 장 제목 후보 5개와 올리기 좋은 시간도 같이 만들어 줘요.
3. **설명글(캡션) 새로 쓰기**
   - 원본 설명글의 **내용과 취지는 그대로** 두고, **문장 표현만 완전히 새로** 써요. 직역하지 않아서 원문 문장을 베끼지 않아요.
   - 원본에 없는 내용은 **지어내지 않아요**. "✅ 원본 내용 대조표"에서 요점이 빠지거나 추가된 게 없는지 직접 확인할 수 있어요.
   - 설명글 맨 끝에 **노출이 잘 되는 해시태그 3개**가 자동으로 붙어요. 넓은 주제 태그 1개, 커뮤니티 태그 1개, 딱 맞는 니치 태그 1개로 골라요.
   - 마음에 안 들면 **🔄 다른 표현으로 다시 쓰기**를 누르세요. 같은 내용을 다른 문장으로 다시 써 줘요.
   - 본문 뒤에는 **📣 댓글 유도 문구 1줄 + 공유·저장 유도 문구 1줄**이 붙어요.
     - 각각 후보 문구가 여러 개 있어서, 눌러서 바꿔 끼울 수 있어요.
     - **"마지막 장 이미지에도 넣기"** 를 누르면 캐러셀 마지막 장에도 들어가요.
     - 인스타가 싫어하는 낚시성 문구("좋아요 누르면…", "5명 태그하세요")는 쓰지 않아요.
   - 최종 설명글 순서: **본문 → CTA → 출처 → 해시태그 3개**
4. **이미지 생성**: 원본의 구도·색감·분위기만 참고해서, **글자 없는 새 이미지**를 AI가 그려요.
5. **글자 입히기**: 번역한 글을 진짜 폰트로 이미지 위에 올려요. AI가 글자를 직접 그리면 깨지기 쉬워서, 글자는 코드가 넣어요.
6. **다운로드**: 1080px PNG 여러 장과 캡션을 ZIP 파일 하나로 받아요.

영상(릴스)을 올리면 **번역된 자막 파일(.srt)**과 **AI 영상 도구용 장면 설명**도 만들어 줘요.

## 🧒 처음 시작하기 (딱 3단계)

### 1단계. Gemini API 키 받기 (5분)

API 키는 AI를 쓰기 위한 **비밀번호** 같은 거예요.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에 들어가서 구글 계정으로 로그인해요.
2. **"Create API key"(API 키 만들기)** 파란 버튼을 눌러요.
3. `AIza...`로 시작하는 긴 글자가 나오면 **복사**해 두세요.
4. ⚠️ **이미지를 만들려면 결제 등록이 필요해요.** 같은 화면의 **"Set up billing"(결제 설정)**에서 카드를 등록하세요.
   - 비용은 대략 게시물 1개 × 3개 나라에 수백 원~천 원 정도예요. 모델과 장수에 따라 달라요.
   - 걱정되면 Google Cloud 결제 화면에서 **예산 알림**(예: 월 1만 원)을 걸어 두세요.

> 🔒 API 키는 절대 다른 사람에게 보여주거나 인터넷에 올리지 마세요.
> 이 앱은 키를 **내 브라우저에만** 저장해요.

### 2단계. 앱을 인터넷에 올리기 (Vercel · 무료 · 10분)

한 번만 해 두면 휴대폰이든 컴퓨터든 주소만 열어서 쓸 수 있어요.

1. [vercel.com](https://vercel.com)에 들어가서 **"Continue with GitHub"**로 가입해요.
2. **"Add New… → Project"**를 눌러요.
3. 목록에서 **`youtube-finder`** 저장소 옆의 **Import**를 눌러요.
4. **Root Directory** 옆의 **Edit**을 누르고 **`instagram-localizer`** 폴더를 골라요. ← 제일 중요해요!
5. **Deploy** 버튼을 눌러요.
6. 1~2분 뒤 🎉 화면이 나오면 주소(예: `https://instagram-localizer-xxx.vercel.app`)를 즐겨찾기 해 두세요.

> 💡 Vercel이 저장소를 못 찾으면 **"Adjust GitHub App Permissions"**를 눌러 `youtube-finder` 접근을 허용해 주세요.

### 3단계. 사용하기

1. 앱 주소를 열면 ⚙️ 설정 창이 떠요. 1단계에서 복사한 **API 키를 붙여넣고 저장**해요.
2. 원본 인스타 게시물을 준비해요.
   - **이미지**: 캐러셀의 각 장을 저장해요. PC라면 이미지를 우클릭해서 저장하거나 캡처해도 돼요.
   - **캡션(게시글)**: 복사해 둬요.
   - **원작자 계정**: `@아이디`를 적어 두세요. 캡션 끝에 출처로 들어가요.
3. 앱에서 **① 정보 입력 → ② 이미지를 순서대로 올리기 → ③ 나라 고르기 → ④ 이미지 방식 고르기**를 하고 **✨ 버튼**을 눌러요.
4. 1~3분 기다리면 **🎨 2. 결과 편집** 탭에 나라별 결과가 나와요. 언제든 위쪽 **📥 1. 원본 넣기** 탭을 눌러 첫 화면으로 돌아갈 수 있어요. 만든 결과는 그대로 남아 있어요.
5. 오른쪽 편집 칸에서 글자, 폰트, 크기, 색, 위치를 다듬어요. 미리보기에 바로 반영돼요.
6. **⬇️ 전체 다운로드(ZIP)**를 누르고, 휴대폰으로 옮겨서 인스타에 올리면 끝이에요.

## 🎯 떡상 확률을 높이는 사용 팁

- **첫 장이 90%예요.** "첫 장 제목 다른 버전"에서 [적용]을 눌러 여러 개를 비교해 보세요.
- **글자가 사진에 묻히면** 🌫️ **그라데이션**을 켜세요.
  - 사진 배경이면 처음부터 아래쪽에 켜져 있어요.
  - **빠른 설정**(은은하게 · 보통 · 진하게)으로 고르고, 위치(아래 · 위 · 위+아래), 색, 높이, 진하기, 부드러움을 조절할 수 있어요.
  - **"모든 장에 똑같이 적용"** 버튼을 누르면 캐러셀 전체가 통일돼요.
  - 사진 전체를 어둡게 하고 싶으면 **"어둡게"** 슬라이더를 쓰세요.
- **줄마다 글자색 바꾸기**: 글자 칸에서 Enter로 줄을 나누고 **🌈 줄마다 다른 색 쓰기**를 켜면, 줄마다 색을 고를 수 있어요.
  - 원본이 줄마다 색이 다르면 AI가 알아서 맞춰 줘요.
- **이미지가 마음에 안 들면** 이미지 설명을 고친 뒤 **🔄 다시 만들기**를 누르세요. 영어로 쓰면 더 정확해요.
- **설명글 첫 줄**이 "더 보기" 전에 보이는 유일한 글이에요. 가장 궁금하게 만드세요.
- **해시태그는 3개면 충분해요.** 많이 붙이면 스팸처럼 보여서 오히려 손해예요. 👀 최종 설명글 미리보기를 그대로 복사해서 붙여넣으세요.
- **"올리기 좋은 시간"**에 맞춰 올리고, 올린 뒤 30분 안에 달리는 댓글에는 꼭 답글을 다세요.
- **나라별로 계정을 따로** 운영하세요. 처음엔 1~2개 나라로 시작해서, 반응이 좋은 나라에 집중하는 걸 추천해요. 한 계정에 여러 언어를 섞으면 알고리즘이 헷갈려요.
- 고르는 원본은 **저장·공유가 많은 정보형**(팁, 리스트, 비교)이 번역해도 잘 떠요.

## ⚖️ 꼭 지켜 주세요 (계정 보호)

- 다른 사람의 게시물을 번역해서 올리는 것도 저작권이 있는 **2차적 저작물**이에요. **원작자 표기는 기본이고, 가능하면 DM으로 허락을 받으세요.**
- **"원본에서 글자만 지우기"** 모드는 허락을 받았거나 내 원본일 때만 쓰세요. 평소에는 **"AI로 새로 그리기"**를 쓰세요.
- 인스타그램은 남의 콘텐츠를 그대로 다시 올린 게시물을 추천에서 덜 보여줘요. 새로 만들고 현지에 맞게 바꿀수록 더 잘 떠요.

## 🛠 (선택) 내 컴퓨터에서 실행하기

개발자가 아니면 건너뛰어도 돼요. 위의 Vercel 방법으로 충분해요.

1. [nodejs.org](https://nodejs.org)에서 **LTS** 버전을 설치해요.
2. 터미널(명령 프롬프트)에서:
   ```bash
   cd instagram-localizer
   npm install
   npm run dev
   ```
3. 화면에 나오는 `http://localhost:5173` 주소를 브라우저에서 열어요.

## 📦 구성

| 파일 | 하는 일 |
|---|---|
| `src/lib/gemini.ts` | Gemini AI 연결 (분석 · 현지화 · 이미지 생성) |
| `src/lib/render.ts` | 이미지 위에 글자를 그리는 엔진 (자동 줄바꿈 · 크기 맞춤 · 일본어 줄바꿈 규칙) |
| `src/lib/countries.ts` | 나라별 말투 규칙과 폰트 목록 (모두 상업용 무료 폰트) |
| `src/components/` | 화면 (업로드 · 편집기 · 설정) |

**앞으로 붙일 수 있는 기능:** 인스타 링크만 넣으면 이미지 자동 수집(Apify 연동), AI 영상 생성(Veo), 나라 추가(미국 · 대만 · 베트남 등).
