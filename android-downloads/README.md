## 업데이트 설치

1. 휴대폰에서 위 APK를 다운로드합니다.
2. **기존 앱을 삭제하지 말고** 받은 파일을 열어 업데이트합니다. 필요하면 해당 다운로드 앱/브라우저의 설치 허용 안내를 직접 확인합니다.
3. 앱을 열고 상단 v2.11을 확인합니다. 결과 편집 → 다운로드·공유 더보기 → **캡컷 다운로드**를 사용합니다.

기존 앱과 앱 ID·서명이 같습니다. 앱 삭제나 데이터 초기화는 저장된 편집 자료를 지울 수 있으므로 하지 마세요.

## 포함 기능

- PC용 캡컷 프로젝트 초안과 휴대폰 편집 자료 ZIP 다운로드.
- 화면 순서대로 사진당 3초 배치, 배경·투명 글자 PNG 분리, 완성 PNG·문구·설명글·사용방법 포함.
- 캡컷 실제 버전별 호환은 미검증입니다. 휴대폰은 자료를 직접 가져오는 방식이며 모바일 .capcut 자동 열기는 아닙니다.
- 글자는 모양을 유지하는 이미지 레이어입니다. 문구를 고치려면 동봉한 원문으로 새 텍스트를 넣습니다.
- 접기/펼치기 편집 화면, 사진 일괄 저장, 다운로드와 공유 분리 등 기존 기능을 유지합니다.

Android 8 이상, 인터넷과 최신 Android System WebView가 필요합니다. PNG는 사진첩, ZIP은 시스템 파일 선택기에서 저장 위치를 고릅니다. 앱은 운영 웹 서비스에 연결합니다. 회원별 키·편집 자료는 PC와 자동 동기화되지 않습니다.
