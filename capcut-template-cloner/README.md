# 🎬 틀복사 스튜디오 (CapCut Template Cloner) — 기획서

> 떡상한 유튜브 영상·채널의 **"고정 틀(포맷)"**을 자동으로 뜯어서,
> **캡컷에서 바로 여는 프로젝트 파일**과 **비슷하지만 다른 변형 3~5개**를 만들어 주는 앱.

이 폴더는 아직 **기획 단계**예요. 코드는 없고, 아래 문서들이 설계도예요.

## 한 줄 요약

```
유튜브 URL / 채널 URL / 스크린샷
        │
        ▼
 ① 틀 분석 ──► TemplateSpec(JSON) ──► ② 캡컷 초안 폴더(.zip)
        │                          ├─► ③ 투명 PNG 오버레이 + 자막 스타일(.srt/.ass)
        │                          └─► ④ 변형 3~5개 (각각 ②③ 세트)
        ▼
 "왜 이 틀이 먹히는지" 리포트
```

## 핵심 결정 5가지

1. **분석은 "AI + 픽셀 계산" 반반.** AI(Gemini)는 *"여기가 제목 박스, 여기가 로고"* 같은 **의미**를 맡고,
   색 코드·박스 크기·자막 위치 같은 **숫자**는 코드가 프레임 픽셀을 직접 재요. AI가 눈대중으로 뽑은 숫자는 틀려요.
2. **"고정 틀" = 여러 프레임에서 안 변하는 부분.** 영상 여러 장면(채널이면 여러 영상)을 겹쳐 보고 픽셀이 그대로인 영역을 틀로 판정해요.
3. **모든 결과는 TemplateSpec 하나로 모아요.** 캡컷 파일, PNG, 미리보기, 변형 모두 이 JSON에서 만들어져요.
   캡컷 포맷이 바뀌어도 내보내기 모듈만 고치면 돼요.
4. **캡컷 파일은 두 가지로 줘요.**
   - 💻 **PC 캡컷용 초안 폴더** — 열면 박스·자막·로고 자리가 이미 깔려 있음 (핵심 기능, 비공식 포맷이라 위험요소 있음)
   - 📱 **어디서나 되는 "틀 팩"** — 투명 PNG 오버레이 + 폰트 + 스타일 카드 (모바일 캡컷에서도 사용 가능, 안전한 대안)
5. **"복제"가 아니라 "구조 복제".** 레이아웃·비율·자막 규칙은 가져오고, **로고·캐릭터·고유 그래픽은 절대 복사하지 않고 내 것으로 교체**해요.

## 만드는 순서 (요약)

| 단계 | 기간 | 끝나면 되는 것 |
|---|---|---|
| **0. 캡컷 검증** 🔄 진행 중 | 3~5일 | 코드로 만든 초안이 **내 캡컷 버전**에서 열리는지 확인 (가장 먼저! 안 되면 전체 방향 수정) → [검증 키트](./phase0/README.md) |
| **1. MVP** | 2~3주 | 스크린샷 3~5장 올리면 → TemplateSpec + PNG 틀 팩 + 미리보기 |
| **2. 캡컷 내보내기** | 1~2주 | 캡컷 PC 초안 폴더 .zip 다운로드 |
| **3. URL 분석 + 변형** | 2주 | 유튜브 URL만 넣어도 분석, 변형 3~5개 자동 생성 |
| **4. 채널 분석** | 1~2주 | 채널 URL → 떡상 영상 골라서 "채널 공통 틀" 추출 (기존 youtube-finder 검색 기능 재사용) |

자세한 내용은 [PLAN.md](./PLAN.md)를 보세요.
