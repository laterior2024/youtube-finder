# 0단계: 캡컷 검증 키트

"코드로 만든 캡컷 파일이 **내 캡컷에서 진짜 열리는지**"를 확인하는 단계예요.
이게 안 되면 앱의 핵심 기능(캡컷 파일 바로 만들기)이 불가능하니까, 다른 걸 만들기 전에 먼저 확인해요.

스크립트를 한 번 실행하면 캡컷 초안 폴더에 **테스트 초안 5개**가 생겨요.

| 초안 이름 | 알아내려는 것 | 성공하면 |
|---|---|---|
| `틀복사_T1_기본열기` | 코드로 만든 초안이 열리기는 하나? | 가장 기본 조건 통과 |
| `틀복사_T2_틀재현` | 예시 틀(위아래 검은 박스 + 제목 + 자막 + 로고)이 색·위치까지 맞게 나오나? | 앱이 만드는 결과물과 같은 형태가 열림 |
| `틀복사_T3_보정` | 격자 위에서 위치·글자 크기·테두리 두께가 얼마나 정확한가? | 스크린샷으로 **환산값을 보정**해서 오차를 없앰 |
| `틀복사_T4_폴더이동` | 소재 경로를 '초안 폴더 기준'으로 적어도 열리나? | 웹 앱에서 **zip 파일로 나눠줄 수 있음** (설치 프로그램 불필요) |
| `틀복사_T5_폰트` | 내 PC의 한글 폰트 파일을 직접 지정할 수 있나? | 지마켓 산스 같은 **캡컷에 없는 폰트도 적용 가능** |

> 🔒 기존 초안은 건드리지 않아요. `틀복사_`로 시작하는 초안만 만들고, 다시 실행하면 그것만 덮어써요.

---

## 준비물
- **PC용 캡컷** (Windows 또는 Mac). 모바일 캡컷은 초안 파일을 가져올 수 없어서 이 테스트를 할 수 없어요.
- **Python 3.9 이상**

## 1. Python 설치 (이미 있으면 건너뛰기)
1. [python.org/downloads](https://www.python.org/downloads/)에서 설치 파일을 받아요.
2. Windows는 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.

## 2. 이 폴더 받기
- GitHub에서 `claude/happy-curie-sevlsg` 브랜치를 고르고 **Code → Download ZIP**으로 받은 뒤 압축을 풀어요.
- 또는 `git clone` 후 `git checkout claude/happy-curie-sevlsg`

## 3. 실행
**캡컷을 완전히 끈 상태에서** 해 주세요.

1. `capcut-template-cloner/phase0` 폴더를 열어요.
2. 터미널을 열어요.
   - Windows: 폴더 위쪽 주소창에 `cmd`라고 치고 Enter
   - Mac: 폴더를 우클릭 → **서비스 → 폴더에서 새로운 터미널 열기**
3. 아래 두 줄을 차례로 입력해요.

```bash
pip install -r requirements.txt
python make_test_drafts.py
```

Mac에서 `python`이 안 되면 `python3`, `pip3`로 바꿔서 입력하세요.

### "캡컷 초안 폴더를 찾지 못했어요"가 나오면
캡컷 → 오른쪽 위 **설정(⚙)** → **초안 위치(Drafts location)** 경로를 복사해서 이렇게 실행해요.
```bash
python make_test_drafts.py --drafts "복사한 경로"
```
기본 위치는 보통 여기예요.
- Windows: `C:\Users\내이름\AppData\Local\CapCut\User Data\Projects\com.lveditor.draft`
- Mac: `/Users/내이름/Movies/CapCut/User Data/Projects/com.lveditor.draft`

## 4. 캡컷에서 확인하기
캡컷을 켜면 초안 목록에 `틀복사_`로 시작하는 초안이 보여요. 안 보이면 캡컷을 완전히 끄고 다시 켜 보세요.
`phase0/phase0_output/` 폴더의 **`…_예상결과.png`**와 캡컷 화면을 나란히 놓고 비교해요.

### T1 기본열기
- [ ] 초안 목록에 보이나요?
- [ ] 열었을 때 오류 없이 **남색 배경 + 흰 글자**가 보이나요?

### T2 틀재현 (`틀복사_T2_틀재현_예상결과.png`와 비교)
- [ ] 위아래 **검은 박스**가 예상결과와 같은 높이인가요?
- [ ] 가운데 회색 **VIDEO** 자리, 오른쪽 아래 흰색 **LOGO** 자리가 맞는 위치에 있나요?
- [ ] 제목이 위쪽 검은 박스 **가운데**에 있나요?
- [ ] 자막이 **흰 글자 + 검은 테두리**로 나오고, 0~3초 / 3~6초 / 6~9초마다 문장이 바뀌나요?
- [ ] 글자 크기가 예상결과와 비교해 **비슷 / 너무 큼 / 너무 작음** 중 어느 쪽인가요?

### T3 보정 (가장 중요한 측정)
- [ ] 빨간 네모 **A·B·C·D**가 분홍 점선 박스 안에 **딱 맞게** 들어가 있나요? (어긋났으면 어느 쪽으로 얼마나?)
- [ ] 미리보기 화면을 **최대한 크게 해서 스크린샷**을 찍어 주세요. 격자가 자 역할을 해서 글자 크기와 테두리 두께를 정확히 계산할 수 있어요.
  - 왼쪽의 주황색 짧은 선 두 개는 "크기 5 / 10 / 15 / 20 글자가 이 높이일 것"이라는 **추측값**이에요. 달라도 괜찮아요. 스크린샷으로 실제 값을 재요.
- (더 좋은 방법) 캡컷에서 **내보내기 → 1080p**로 영상을 뽑아서 첫 화면을 캡처해도 돼요.

### T4 폴더이동
- [ ] 배경이 **보라색**으로 보이나요? → 성공
- [ ] "소재 없음(Media missing)" 같은 빨간 표시가 뜨나요? → 실패 (실패해도 괜찮아요. 다른 배포 방법을 써요.)

### T5 폰트
- [ ] 위 줄(캡컷 기본 폰트)과 아래 줄(내 PC의 한글 폰트)의 **글씨체가 다르게** 보이나요? → 성공
- [ ] 둘이 똑같이 보이면 → 폰트 지정 실패

## 5. 결과 보내기
아래 네 가지를 채팅에 보내 주세요. [RESULTS.md](./RESULTS.md) 양식을 채워서 보내도 돼요.

1. **캡컷 버전** (캡컷 → 설정 또는 메뉴 → 정보에서 확인) + **Windows / Mac**
2. 위 체크리스트 결과
3. **T2, T3 스크린샷**
4. `phase0/phase0_output/phase0_report.json` 파일 내용

## 결과에 따른 다음 단계

| 결과 | 판단 | 다음 할 일 |
|---|---|---|
| T1·T2 성공, T4 성공 | 🟢 **최상** | 웹 앱에서 캡컷 초안 zip을 바로 나눠줌 |
| T1·T2 성공, T4 실패 | 🟡 **가능** | 초안 zip + "경로 맞춰주는 작은 설치 도우미" 제공, 또는 PC용 도우미 앱 |
| T1 실패 | 🔴 **방향 전환** | 캡컷 초안 대신 **틀 팩**(투명 PNG + 스타일 카드)을 핵심 결과물로. 필요하면 캡컷 버전별로 다시 시도 |
| T5 실패 | 🟡 | 폰트는 캡컷 내장 폰트 중 가장 비슷한 것으로 대체 + 폰트 설치 안내 |

T3 스크린샷을 받으면 `spec_to_capcut.py`의 `CALIBRATION` 값(글자 크기, 테두리 환산)을 실제 값으로 바꾸고 다시 테스트해요.

## 자주 생기는 문제
- **`pip`를 찾을 수 없어요**: Python 설치 때 PATH 체크를 안 한 경우예요. `python -m pip install -r requirements.txt`로 해 보세요.
- **Mac에서 `pymediainfo` 오류**: `brew install mediainfo`를 설치한 뒤 다시 실행하세요.
- **초안이 목록에 안 보여요**: 캡컷을 완전히 끄고(작업표시줄/Dock에서도 종료) 다시 켜세요. `--drafts` 경로가 캡컷 설정의 '초안 위치'와 같은지도 확인하세요.
- **테스트 초안 지우기**: 캡컷 초안 목록에서 삭제하거나 초안 폴더에서 `틀복사_` 폴더를 지우면 돼요.

## 파일 설명
| 파일 | 역할 |
|---|---|
| `make_test_drafts.py` | 테스트 초안 5개 만들기 (실행 파일) |
| `spec_to_capcut.py` | TemplateSpec → 캡컷 값 변환 공식 + 보정값. 검증 끝나면 앱(TypeScript)으로 옮길 핵심 로직 |
| `assets.py` | 박스·자리표시·격자 PNG, 예상결과 이미지 만들기 |
| `RESULTS.md` | 결과 기록 양식 |

캡컷 초안 파일은 오픈소스 [pyCapCut](https://github.com/GuanYixuan/pyCapCut)(`pip install pycapcut`)으로 만들어요. 코드는 복사하지 않고 라이브러리로 설치해서 써요.
