# 대용량·별도 보관 자료 목록

기준: 2026-10-08, GitHub main의 v2.6 기준 트리 91개 파일과 이관 변경 파일.

## 저장소에서 확인한 파일

- 5 MiB 이상 파일: **없음**.
- 영상·이미지·음원·압축 미디어 확장자 파일: **없음**.
- 앱 실행에 필요한 별도 로컬 미디어: **없음**.
- 글꼴은 index.html에 지정된 Google Fonts·jsDelivr 주소에서 내려받습니다. 인터넷이 필요합니다.
- 소스의 가장 큰 파일군은 package-lock.json·AI 처리 코드이며 대용량 개인 미디어가 아닙니다.

## 별도로 보관해야 하는 사용자 자료

| 자료 | 현재 위치 / 확인 범위 | 이관 방법 | GitHub 포함 |
| --- | --- | --- | --- |
| 원본 이미지·영상·음원 | 사용자 선택 폴더. 현재 PC 파일 접근 도구 장애로 미추적 파일 목록은 미검사 | 본인 저장장치·개인 클라우드에 직접 복사 | 제외 |
| 생성된 이미지·설명글·자막 등 | 앱의 결과 편집 화면 | 전체 다운로드 ZIP으로 내려받고 백업 | 제외 |
| 편집 중 프로젝트 | 기존 기기·브라우저·사이트 주소·회원별 IndexedDB | 자동 이전·편집 상태 가져오기 기능 없음. 기존 브라우저 보존 및 결과/원본 별도 백업 | 제외 |

| 개발 설치물 | node_modules·dist·release 등 | npm ci·빌드·package 명령으로 재생성 | 제외 |

현재 PC에서 파일 접근이 안 되므로 **개인 미디어가 전혀 없다는 뜻은 아닙니다.** 위 “없음”은 검사한 GitHub 소스에 대한 결과입니다. 브라우저 데이터와 GitHub 미추적 파일은 소스 ZIP에 포함되지 않습니다.

향후 파일을 추가할 때는 파일명, 크기, 원본 위치, 복구할 상대 위치, 백업 위치, 사용 권한을 이 목록에 기록하세요. 개인 경로나 비공개 공유 링크·토큰은 공개 저장소에 기록하지 않습니다. 큰 자료는 local-media/ 또는 backups/처럼 Git에서 제외되는 폴더에 두고 별도로 백업합니다.
