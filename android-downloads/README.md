## 설치·업데이트

1. **기존 앱을 삭제하지 말고** 새 APK를 열어 업데이트합니다. 기존 앱과 같은 ID·인증서입니다.
2. 필요하면 다운로드한 브라우저/파일 앱의 '이 출처 허용'을 켭니다. 앱을 다시 열고 v2.10을 확인합니다.
3. 신규 설치는 기존 계정 로그인과 본인의 Gemini 키 설정이 필요합니다. PC와 앱의 키·편집 자료는 자동 동기화되지 않습니다.

## 변경 내용

- 사진 미리보기, 사진 저장, 최종 설명글 복사를 기본으로 둡니다. 배경·그라데이션·글자·설명글/해시태그/게시 팁·유사도·영상 자료는 기본적으로 접혀 있습니다. 필요한 메뉴를 펼치고 위·아래의 접기 버튼으로 닫습니다. 기존 내용은 삭제하지 않았습니다.
- PC·모바일에서 편집 중 사진에 반영되는 모습을 확인합니다.
- 새 글꼴은 프리텐다드(일본어·중국어는 Noto 보완)이며 새 썸네일 두 줄은 아래, 세 줄은 가운데를 노란색으로 시작합니다. 명시적인 줄바꿈·문장 기준으로 처리하며 기존 편집과 수동 색상은 유지합니다.
- '사진 N장 한 번에 저장'으로 앱은 사진첩의 InstagramLocalizer 앨범에 순차 저장합니다. Android 8·9는 저장 권한이 필요합니다. PC Chrome·Edge는 폴더를 한 번 선택하고 새 하위 폴더에 PNG를 저장합니다. 미지원 브라우저는 사진 전용 ZIP으로 받습니다.
- 전체 ZIP·별도 공유는 '다운로드·공유 더보기'에 있습니다. **다운로드 후 공유 팝업은 뜨지 않습니다(v2.10 APK 필요).** 공유는 파일 준비 후 '공유 창 열기'를 명시적으로 누릅니다. 준비 이후 편집했다면 준비 취소 후 다시 준비합니다.

Android 8 이상, 인터넷과 최신 Android System WebView가 필요합니다. APK 126,258바이트(약 126KB); 웹 캐시·사용자 자료·공유 임시 파일 용량은 별도입니다. 공유 캐시는 앱 전용 폴더만 제공하며 24시간 지난 파일은 다음 공유 시 정리합니다.
