# ✂️ 쇼츠 자동 편집기 (이슈·감동·정보·스토리) — 1주차: CapCut 프로젝트 파일 열어 보기

이번 주 목표는 딱 하나예요.

> **우리 프로그램이 CapCut 프로젝트 파일을 읽고, 자막을 바꿔서 저장한 뒤, CapCut에서 그 프로젝트가 제대로 열리는지 확인하기.**

이게 되면 나중에 "자동으로 자르고, 자막 넣고, 효과음 넣은 결과"를 CapCut 프로젝트로 저장할 수 있어요.
이게 안 되면 나머지 계획을 바꿔야 해서 맨 먼저 확인하는 거예요.

> ⚠️ 이 도구는 **PC용 CapCut(Windows / Mac)** 전용이에요. 휴대폰 CapCut은 안 돼요.

---

## 준비물

1. **PC용 CapCut** 설치
2. **파이썬 3.9 이상** 설치 ([python.org](https://www.python.org/downloads/))
   - Windows는 설치 첫 화면에서 **"Add python.exe to PATH"를 꼭 체크**하세요.
3. 이 폴더(`shorts-autocut`)를 내 컴퓨터에 받기

따로 설치할 파이썬 패키지는 없어요.

---

## 따라 하기

### 1단계. CapCut에서 "틀" 프로젝트 만들기 (사람이 직접)

1. CapCut을 켜고 **새 프로젝트**를 만들어요.
2. 짧은 영상 하나를 타임라인에 올려요.
3. **자막(텍스트)을 2~3개** 넣어요. 글자는 아무거나 괜찮아요. 폰트, 색, 테두리를 원하는 쇼츠 스타일로 꾸며 두세요. **이 스타일이 그대로 복사돼요.**
4. 가능하면 효과음 하나, 장면 전환 하나도 넣어요. (나중 주차에서 써요)
5. 프로젝트 이름을 **`틀_쇼핑쇼츠`**로 바꾸고 **CapCut을 완전히 꺼요.**
   (켜져 있으면 CapCut이 파일을 다시 덮어쓸 수 있어요.)

### 2단계. 터미널 열기

- **Windows**: `shorts-autocut` 폴더를 열고, 주소창에 `cmd` 입력 후 엔터
- **Mac**: 터미널을 열고 `cd ` (띄어쓰기 포함)를 입력한 뒤 폴더를 끌어다 놓고 엔터

아래 명령에서 `python`이 안 되면 `python3` 또는 `py`로 바꿔 보세요.

### 3단계. 내 CapCut 프로젝트 찾기

```bash
python capcut_draft.py find
```

`틀_쇼핑쇼츠`가 목록에 보이면 성공이에요.

> 목록이 비어 있으면: CapCut → 설정 → **프로젝트 저장 위치**를 확인하고 이렇게 알려 주세요.
> ```bash
> python capcut_draft.py --projects-dir "여기에_폴더_경로" find
> ```
> (`--projects-dir`은 항상 `find`/`inspect` 같은 명령어 **앞에** 써요.)

### 4단계. 프로젝트 들여다보기

```bash
python capcut_draft.py inspect 틀_쇼핑쇼츠
```

이렇게 나오면 성공이에요.

```
📂 프로젝트: 틀_쇼핑쇼츠
   전체 길이: 12.40초   화면 크기: 1080x1920
🎞️  타임라인 줄(tracks)
   1. video 줄 — 조각 1개
   2. text 줄 — 조각 3개
💬 자막 글자
   1. '안녕'
   ...
✅ 읽기 성공! 이 CapCut 버전은 우리 프로그램이 다룰 수 있어요.
```

❌ **"암호화하는 것 같아요"**라고 나오면 아래 [암호화되어 있을 때](#암호화되어-있을-때)를 보세요.

### 5단계. 틀을 복사해서 자막 바꾼 새 프로젝트 만들기

```bash
python capcut_draft.py clone 틀_쇼핑쇼츠 --name 테스트1 --text "이거 미쳤다 ㄷㄷ" --text "채소 3초 컷" --text "링크는 고정댓글"
```

- `--text`를 쓴 순서대로 1번, 2번, 3번 자막이 바뀌어요.
- 폰트, 색, 위치 같은 스타일은 **틀 그대로** 유지돼요.
- 틀 프로젝트는 건드리지 않아요.

### 6단계. CapCut에서 열어 보기 🎉

1. CapCut을 켜요.
2. 프로젝트 목록에 **`테스트1`**이 보이는지 확인해요.
3. 열어서 자막이 바뀌었는지, 영상이 잘 재생되는지 확인해요.

**여기까지 되면 1주차 성공이에요!** ✅

## 잘 안 될 때

### `테스트1`이 목록에 안 보여요
CapCut 버전에 따라 복사한 폴더를 목록에 바로 올리지 않을 수 있어요. 그럴 때는 **그 자리에서 고치는 방식**을 써요.

1. CapCut에서 `틀_쇼핑쇼츠`를 **복제**해요 (프로젝트 카드 `…` → 복제). 이름은 `테스트2`로 해요.
2. CapCut을 완전히 끄고:
   ```bash
   python capcut_draft.py edit 테스트2 --text "이거 미쳤다 ㄷㄷ" --text "채소 3초 컷"
   ```
3. CapCut을 켜서 `테스트2`를 열어요.

원래 파일은 `draft_content.json.backup-날짜` 이름으로 백업돼요. 문제가 생기면 백업 파일 이름을 원래대로 바꾸면 돼요.

### 한 번은 열렸는데, 나갔다가 다시 들어가면 안 열려요
새 CapCut 버전은 타임라인을 `Timelines/<타임라인 id>/` 폴더에도 저장해요. 프로젝트 파일의 `id`가 이 폴더 이름과 다르면 처음 한 번은 열리지만, CapCut이 닫으면서 저장한 뒤부터는 안 열려요.
(처음 버전의 `clone`이 이 id를 바꿔서 생긴 문제예요. 지금 버전에서는 고쳐졌어요.)

CapCut을 **완전히 끄고** 아래를 실행하면 고쳐져요.
```bash
python capcut_draft.py repair 테스트1
```
그래도 안 되면 폴더 안을 비교해서 알려 주세요.
```bash
python capcut_draft.py diagnose 테스트1 틀_쇼핑쇼츠
```

### 암호화되어 있을 때
최근 일부 CapCut PC 버전은 프로젝트 파일을 암호화해서 외부 프로그램이 읽을 수 없어요.

1. 지금 쓰는 CapCut 버전을 적어 두세요 (CapCut → 설정 → 정보).
2. 프로젝트 파일이 암호화되지 않는 **예전 버전의 CapCut PC**를 설치하고, **자동 업데이트를 꺼요.**
3. 그 버전에서 1단계부터 다시 해 보세요.
4. 어느 버전에서 됐는지 이 README 맨 아래 "확인된 버전" 표에 적어 두세요.

그래도 안 되면 계획 B로 가요. 앱이 **완성 MP4 + 자막 파일(SRT)**을 만들고, 그걸 CapCut으로 불러와서 손보는 방식이에요.

### 한글이 깨져 보여요
Windows `cmd`에서 먼저 `chcp 65001`을 입력하고 다시 해 보세요.

## 파일 설명

| 파일 | 하는 일 |
|---|---|
| `capcut_draft.py` | CapCut 프로젝트 찾기 / 들여다보기 / 복사 / 자막 바꾸기 |
| `test_capcut_draft.py` | 가짜 프로젝트로 위 기능이 맞게 도는지 확인하는 테스트 (`python -m unittest test_capcut_draft.py`) |
| `silence_cut.py` | (2주차) 무음을 찾아 자르고 조각들을 CapCut 영상 줄에 넣기 |
| `test_silence_cut.py` | 2주차 테스트 (ffmpeg가 있으면 진짜 영상으로도 확인) |
| `auto_subtitle.py` | (3주차) 받아쓰기 → 쇼츠 자막 → 무음 컷과 함께 CapCut 프로젝트 + .srt |
| `test_auto_subtitle.py` | 3주차 테스트 |
| `analyze_sample.py` | (4주차) 샘플 쇼츠 분석 → 성공공식 카드(JSON) |
| `test_analyze_sample.py` | 4주차 테스트 |
| `auto_edit.py` | (5주차) 공식대로 장면 고르기 → 8~35초 편집 + 자막 + 훅 제목 → CapCut 프로젝트 |
| `test_auto_edit.py` | 5주차 테스트 |

### CapCut 프로젝트 파일 구조 (참고)

```
테스트1/
├── draft_content.json    ← 타임라인 전부 (버전에 따라 draft_info.json)
│     ├── materials        재료: videos, audios, texts, transitions ...
│     └── tracks           줄: video / audio / text, 줄마다 segments(조각)
│           └── target_timerange { start, duration }  ← 단위: 마이크로초 (1초 = 1,000,000)
└── draft_meta_info.json  ← 프로젝트 이름, ID, 폴더 위치
```

# ✂️ 2주차: 무음 자동 컷 → CapCut 프로젝트

원본 영상에서 **조용한 부분을 자동으로 찾아 잘라내고**, 남은 조각들을 틀 프로젝트의 영상 줄에 붙여서 CapCut 프로젝트로 만들어요.

## 준비 (처음 한 번만)

1. 새 파일 두 개를 `shorts-autocut` 폴더에 받아요: `silence_cut.py`, 그리고 **새 버전 `capcut_draft.py`**
2. 영상 도구(ffmpeg)를 설치해요. 검은 창에:
   ```
   python -m pip install imageio-ffmpeg
   ```
3. 원본 영상을 `shorts-autocut` 폴더에 `원본.mp4` 이름으로 넣어요.
   ⚠️ CapCut은 이 파일을 **그 자리에서** 불러와요. 나중에 옮기거나 지우면 영상이 안 보여요.

## 따라 하기

### 1단계. 자를 계획만 먼저 보기 (아무것도 안 만들어요)
```
python silence_cut.py 원본.mp4 --dry-run
```
무음 구간, 남길 조각, 결과 길이가 나와요.

### 2단계. 결과가 마음에 안 들면 숫자 조절하기

| 이렇게 되면 | 이렇게 바꿔요 |
|---|---|
| 너무 많이 잘려요 (말이 끊겨요) | `--threshold -45` (더 작은 소리만 무음으로 봐요) |
| 너무 적게 잘려요 (배경음 때문에) | `--threshold -30` |
| 짧은 숨 쉬는 틈까지 잘려요 | `--min-silence 0.7` |
| 말 끝이 뚝 끊겨요 | `--padding 0.2` |

예: `python silence_cut.py 원본.mp4 --threshold -45 --dry-run`

### 3단계. CapCut 프로젝트 만들기
CapCut을 **완전히 끄고**:
```
python silence_cut.py 원본.mp4
```
→ `원본_무음컷` 프로젝트가 생겨요. 이름을 정하려면 `--name 무음컷1`을 붙여요.
틀 이름이 `틀_쇼핑쇼츠`가 아니면 `--template 내틀이름`을 붙여요.

### 4단계. CapCut에서 확인
- 영상 줄이 여러 조각으로 나뉘어 있나요?
- 조용한 부분이 빠졌나요?
- **나갔다가 다시 열어도** 잘 열리나요?

## 알아 두기
- 틀의 **자막은 그대로** 남아요. 영상이 틀보다 짧아지면 끝나는 자막은 길이에 맞게 잘려요. (자막 자동 생성은 3주차)
- 가로 영상은 세로 화면(1080x1920)에 **위아래 검은 띠**가 생길 수 있어요. (세로 맞추기는 뒤 주차)
- 음악만 깔린 영상은 무음이 거의 없어서 잘 안 잘려요. 정상이에요.

# 💬 3주차: 외국어 말 → 한국어 쇼츠 자막 자동 넣기

2주차의 무음 컷에 더해서, 원본 영상의 **말을 받아쓰고(Whisper)**, **한국어 쇼츠 말투로 바꿔서(Gemini)**, **말하는 시간에 맞춰** 자막을 넣어요.
자막 모양(폰트, 색, 테두리, 위치, 애니메이션)은 **틀의 첫 번째 자막을 그대로** 따라가요.

## 준비 (처음 한 번만)

1. 새 파일 `auto_subtitle.py`를 `shorts-autocut` 폴더에 받아요.
2. 받아쓰기 도구를 설치해요. (1~2분 걸려요)
   ```
   python -m pip install faster-whisper
   ```
3. **Gemini API 키 만들기**
   1. https://aistudio.google.com/apikey 에 구글 계정으로 들어가요.
   2. **API 키 만들기(Create API key)**를 눌러 키를 복사해요.
   3. `shorts-autocut` 폴더에 **`api_key.txt`** 파일을 만들고(메모장 → 다른 이름으로 저장), 키 한 줄만 붙여 넣고 저장해요.
   ⚠️ 이 키는 비밀번호와 같아요. 다른 사람에게 보여 주지 마세요.

## 따라 하기

### 1단계. 자막 결과만 먼저 보기
```
python auto_subtitle.py 원본.mp4 --dry-run
```
- 처음에는 받아쓰기 모델을 내려받느라 **몇 분** 걸려요. 두 번째부터는 빨라요.
- 받아쓴 결과는 `원본.transcript.json`에 저장돼서, 다시 실행하면 받아쓰기를 건너뛰어요.
- 원문 → 바뀐 자막이 화면에 나오고, `원본_자막.srt` 자막 파일도 생겨요.

### 2단계. 마음에 들게 조절하기

| 원하는 것 | 붙일 것 |
|---|---|
| 자막을 더 짧게 | `--max-chars 8` |
| 말투 바꾸기 | `--style "반말, 친구한테 추천하듯, 감탄사 많이"` |
| 받아쓰기가 부정확해요 | `--whisper-model medium` (느리지만 정확) |
| 언어를 잘못 알아들어요 | `--language en` (영어) / `zh` (중국어) / `ja` (일본어) |
| 번역 없이 원문 그대로 | `--no-translate` |
| 무음은 자르지 않기 | `--no-cut` |

Gemini는 실행할 때마다 조금씩 다른 자막을 줘요. 마음에 안 들면 다시 실행해 보세요.

### 3단계. CapCut 프로젝트 만들기
Gemini는 실행할 때마다 자막을 새로 써요. **1단계에서 확인한 자막을 그대로** 쓰려면 저장된 `.srt` 파일을 넘겨요.
1. (선택) `원본_자막.srt`를 **메모장으로 열어서** 마음에 안 드는 글자를 고치고 저장해요. 숫자와 시간 줄은 건드리지 마세요.
2. CapCut을 **완전히 끄고**:
   ```
   python auto_subtitle.py 원본.mp4 --srt 원본_자막.srt --name 자막1
   ```
   이러면 받아쓰기와 Gemini를 건너뛰어요 (돈도 안 들어요).
   ⚠️ 무음 컷 설정(`--threshold` 등)은 `.srt`를 만들 때와 **같게** 써야 시간이 맞아요.

`.srt` 없이 `python auto_subtitle.py 원본.mp4 --name 자막1`로 하면 Gemini가 자막을 새로 써서 바로 넣어요.

### 4단계. CapCut에서 확인
- 자막이 **말하는 순간에** 나오나요?
- 자막 모양이 틀과 같나요?
- **나갔다가 다시 열어도** 잘 열리나요?

## Gemini 402 오류 ("prepayment credits are depleted")
프로그램 문제가 아니라, API 키가 속한 **AI Studio 프로젝트의 선불 크레딧이 0원**이라는 뜻이에요. 둘 중 하나를 하세요.
- **크레딧 충전:** https://ai.studio/projects 에서 그 프로젝트의 결제(Billing)에 크레딧을 추가해요. 영상 1개에 드는 비용은 아주 적어요.
- **결제가 연결되지 않은 새 프로젝트의 키 쓰기:** https://aistudio.google.com/apikey 에서 **새 프로젝트로** 키를 만들고 `api_key.txt`를 그 키로 바꿔요. 무료 사용량 안에서 쓸 수 있어요 (한도가 작아서 429 오류가 나면 1분 뒤 다시).

기다리는 동안에는 `--no-translate`로 CapCut에 자막이 들어가는 것부터 확인할 수 있어요.

## 알아 두기
- 틀에 있던 자막은 **모두 새 자막으로 바뀌어요.** 틀에는 원하는 스타일의 자막 1개만 있으면 돼요.
- 말이 없는 영상(음악만 있는 영상)은 자막이 생기지 않아요.
- Gemini는 원문에 없는 가격·효과를 **지어내지 말라고** 지시했지만, 올리기 전에 꼭 한 번 읽어 보세요.

# 🏆 4주차: 잘 된 샘플 쇼츠 → "성공공식 카드" 만들기

잘 된 쇼츠 여러 개를 넣으면, 공통점을 뽑아서 **성공공식 카드(`성공공식.json`)** 한 장으로 정리해요.

| 누가 | 무엇을 알아내나요 |
|---|---|
| 프로그램이 직접 재요 (무료) | 길이, 컷(장면 바뀜) 수와 위치, 평균 장면 길이, 첫 3초 컷 수, 무음 비율 |
| Gemini가 영상을 보고 들어요 | 훅(첫 2초), 구조(훅→문제→시연→…), 자막 스타일, 효과음 위치, 전환, 음악, 말투, 구매 유도, 잘 된 이유 |

## 준비
1. 새 파일 `analyze_sample.py`, 그리고 **새 버전 `auto_subtitle.py`**를 받아요. (analyze_sample.py가 auto_subtitle.py 안의 기능을 같이 써요)
2. 잘 된 쇼츠 영상 **2~5개**를 `shorts-autocut` 폴더에 넣어요. 이름은 `샘플1.mp4`, `샘플2.mp4`처럼 짧게.
   - 가능하면 **같은 카테고리**(예: 생활용품)끼리 모아요. 섞이면 공식이 흐려져요.

## 따라 하기

### 1단계. 무료로 먼저 재 보기 (Gemini 안 씀)
```
python analyze_sample.py 샘플1.mp4 샘플2.mp4 샘플3.mp4 --no-ai
```
길이, 컷 수, 평균 장면 길이가 나와요. 컷 수가 이상하면 `--scene-threshold 0.2`(더 많이 찾기) 또는 `0.4`(덜 찾기).

### 2단계. Gemini로 전체 분석
```
python analyze_sample.py 샘플1.mp4 샘플2.mp4 샘플3.mp4 --out 공식_생활.json
```
- 영상마다 1~2분 걸릴 수 있어요. 분석 결과는 `샘플1.analysis.json`처럼 저장돼서, **다시 실행하면 재사용**해요 (돈 안 들어요).
- 다시 분석하고 싶으면 `--refresh`.
- ⚠️ 샘플 영상은 분석을 위해 Google(Gemini)로 보내져요.

### 3단계. 결과 읽고 "나만의 공식"으로 고치기
화면에 목표 길이, 구조(몇 초~몇 초에 무엇), 자막 스타일, 효과음 규칙, **나만의 공식 아이디어 3개**가 나와요.
`공식_생활.json`을 **메모장으로 열어서** 숫자나 글자를 바꾸면 그게 나만의 공식이에요.
- 예: `"한줄최대글자수": 10` → `8`, `"강조색": "노랑"` → `"형광초록"`
- 따옴표(`"`)와 쉼표(`,`)는 지우지 마세요. 고친 뒤 이상하면 2단계를 다시 실행하면 새로 만들어져요.

## 알아 두기
- 샘플은 **공식을 배우는 용도**예요. 샘플의 장면이나 문장을 그대로 쓰면 안 돼요.
- 카드의 숫자(길이, 컷 속도)는 Gemini가 아니라 **프로그램이 잰 값**이라 정확해요.

# 🎬 5주차: 성공공식대로 원본 → 8~35초 쇼츠 자동 편집

> 이 도구는 **이슈·감동·정보·스토리 쇼츠**용이에요. (4주차 공식 카드도 이 장르로 분석하게 바뀌었어요)

4주차에서 만든 **공식 카드**를 보고, Gemini가 원본 영상에서 **공식 구조(훅→배경→전개→클라이맥스→참여유도)에 맞는 장면**을 골라요.
- 가장 강한 장면(결말·반전)을 **맨 앞 훅으로** 옮길 수 있어요.
- 고른 장면 안의 **무음은 잘라내고**, 대사는 **공식의 말투·글자 수**로 자막을 만들어요.
- 첫 2~3초에 **훅 제목**, 마지막 2~3초에 **참여유도 문구**를 화면 위쪽에 따로 넣어요.
- 전체 길이는 **35초를 넘지 않게** 프로그램이 한 번 더 맞춰요.

## 준비
새 파일 `auto_edit.py`, 그리고 새 버전 `auto_subtitle.py`, `analyze_sample.py`를 받아요.

## 따라 하기

### 1단계. 편집 계획만 먼저 보기
```
python auto_edit.py 원본.mp4 --formula 공식_생활.json --dry-run
```
- 어떤 장면을 어떤 순서로 썼는지, 훅 제목, 자막, 완성 길이가 나와요.
- 계획은 `원본_편집.plan.json`에 저장돼요.

### 2단계. (선택) 계획 고치기
`원본_편집.plan.json`을 **메모장으로 열어서** 고쳐요.
- `"훅제목"`, `"참여유도"` 글자 바꾸기
- `"구간"`의 `"시작"`, `"끝"` 숫자(원본 기준 초) 바꾸기, 장면 순서 바꾸기
- `"자막"`의 `"글자"` 고치기
따옴표와 쉼표는 지우지 마세요.

### 3단계. CapCut 프로젝트 만들기 (CapCut을 끄고)
```
python auto_edit.py 원본.mp4 --plan 원본_편집.plan.json --name 편집1
```
저장된 계획을 그대로 써서 **Gemini를 다시 부르지 않아요** (돈 안 들어요).

### 4단계. CapCut에서 확인
- 장면 순서가 계획대로인가요? 훅이 맨 앞인가요?
- 훅 제목이 **화면 위쪽**에 나오나요? (위치가 이상하면 `--title-y 0.4`처럼 조절: -1 아래 ~ 1 위)
- 자막 타이밍이 말과 맞나요?
- **나갔다가 다시 열어도** 잘 열리나요?

## 조절하기
| 원하는 것 | 붙일 것 |
|---|---|
| 길이를 직접 정하기 | `--target 25` |
| 무음을 자르지 않기 (음악만 있는 영상) | `--no-silence-cut` |
| 자막 번역 안 하기 | `--no-translate` |

⚠️ 원본 영상은 장면을 고르기 위해 Google(Gemini)로 보내져요. 원본 영상의 저작권도 꼭 확인하세요.
