# 인스타그램 게시물 자동생성 (v2.5)

사진과 설명글을 10개 나라에 맞게 편집하는 웹 앱입니다. 회원가입 → 이메일 인증 → 관리자 승인 후 사용할 수 있습니다.

## 처음 사용하기

1. 회원가입 후 이메일 인증을 완료하고 로그인합니다.
2. 관리자가 승인하면 작업 화면이 열립니다.
3. API 키 없이 사용하려면 사진을 직접 올리거나 빈 게시물에서 **직접 편집**을 선택합니다. 글자·배경색·설명글을 편집하고 PNG 또는 ZIP으로 받습니다.
4. AI 분석·번역·배경 생성은 설정에 본인의 Gemini API 키를 넣어 사용합니다. 링크에서 원본을 가져오는 Apify 기능은 선택 사항입니다.
5. 완성한 결과를 확인한 뒤 내려받아 인스타그램에 직접 올립니다.

AI 서비스의 사용료와 이용 가능 모델은 회원 본인 계정에 따릅니다. 관리자에게 회원의 API 키가 전달되지 않습니다. 키는 기본적으로 현재 탭에 회원별로 보관합니다. 설정에서 **이 기기에 키 기억하기**를 직접 선택하면 현재 브라우저에 보관해 다음 방문에 불러옵니다. 로그아웃하면 기억한 키도 지웁니다. PC와 휴대폰, 서로 다른 브라우저 사이에는 키가 자동으로 공유되지 않습니다. 기기 저장이 막힌 브라우저에서는 옵션을 끄고 현재 화면에서 사용할 수 있습니다.

## 관리자

상단 **회원 관리**에서 이름·이메일 검색, 승인 대기 필터, 승인·정지·거절, 하루 요청 한도, 공지와 점검 모드, 최근 관리 기록을 확인합니다. 관리자 계정의 권한·상태는 이 화면에서 바꿀 수 없습니다.

초기 관리자 이메일은 DB 설치 파일의 private.owner_bootstrap에 지정합니다. 설치 전에 예시 주소 owner@example.com을 본인의 관리자 이메일로 바꾸세요. 운영 중인 프로젝트에는 기존 설정이 유지됩니다. 해당 이메일의 실제 인증을 완료한 계정만 최초 관리자가 되며 회원가입 입력값으로 관리자 권한을 만들 수 없습니다.

하루 요청 한도는 한국 날짜 기준입니다. AI 호출과 원본 이미지 중계 요청 시도를 계산하며, 게시물 하나가 여러 요청을 사용할 수 있습니다. 외부 서비스의 결제 상한이 아니므로 Google·Apify에서 비용을 확인하세요. BYOK 호출은 회원 브라우저에서 해당 서비스로 직접 전달됩니다.

## v2.5 모바일 오류 수정

- 키가 없는 경우 결과 편집의 모든 AI 요청 전에 설정을 안내합니다. 직접 편집·다운로드는 계속 가능합니다.
- 작은 화면의 키 입력칸 넘침, 자동 대문자·맞춤법 교정, 붙여넣은 공백 처리를 보완했습니다.
- **키 연결 확인**은 Google 모델 목록만 조회합니다. 콘텐츠를 생성하지 않으며 이미지 모델의 권한·요금제·잔여 한도까지 보장하지는 않습니다.
- 키 무효, 사이트 제한, Google 접근 권한, 사용량 초과를 구분합니다. 기기에서 Google로 직접 요청하는 기존 BYOK 방식은 유지합니다.

## v2.4에서 개선한 점

- 회원별 작업 저장과 관리자 승인, 서버의 권한 검사, 일일 요청 제한.
- 키 없이 직접 편집. 관리자·AI·ZIP 코드는 필요한 때 불러옵니다.
- 일부 생성 실패를 완료로 표시하지 않으며 실패한 나라·배경만 다시 시도합니다.
- 재시도할 때 성공한 나라의 편집을 보존합니다.
- 영상의 발화·화면 글·장면 정보를 설명글에 반영합니다.
- ZIP에 설명글·대체 텍스트·자막·영상 장면 설명을 함께 넣습니다.
- 비교 원본이 없으면 유사도를 판단 보류로 표시합니다. 점수는 참고이며 권리나 성과를 보증하지 않습니다.
- 사진은 긴 변 1536px 이하 WebP로 줄여 저장합니다. 한 장 20MB, 게시물당 20장, 영상 100MB 제한을 적용합니다.
- 이미지 중계는 허용된 HTTPS 주소, 이동할 주소, 파일 종류·크기·응답 시간을 검사합니다.
- 다운로드가 자동 시작되지 않으면 화면 아래 **다시 받기** 링크를 사용할 수 있습니다.

## 저장과 범위

사진·작업은 현재 기기·브라우저의 회원별 저장소에 자동 저장됩니다. 서버에 사진을 보관하거나 다른 기기로 동기화하지 않습니다. 공용 PC에서는 작업을 내려받은 후 앱의 처음부터 기능으로 정리하세요. v2.3의 기존 로컬 저장소는 삭제하지 않지만 새 회원 저장소로 자동 이전하지 않습니다. 기존 작업은 업데이트 전 다운로드해 두세요.

영상은 분석·자막·장면 설명까지 지원합니다. 완성된 영상 제작, 인스타그램 자동 업로드, DM 자동 발송은 포함하지 않습니다. AI 결과의 사실·출처와 사용할 권리는 게시 전 확인합니다.

## 설치와 배포

Node.js 24 환경에서 실행합니다.

1. Supabase 프로젝트의 SQL Editor에서 supabase/migrations/202610030001_members.sql을 새 프로젝트에 한 번 실행합니다.
2. .env.example을 참고해 Supabase URL과 공개용 publishable key를 설정합니다. service_role 또는 secret 키는 필요하지 않습니다.
3. Supabase Authentication에서 Site URL을 실제 서비스 주소로 지정하고 개발 주소를 Redirect URLs에 추가합니다. 이메일 인증은 켜 둡니다.
4. **일반 회원을 받기 전에 Custom SMTP를 연결합니다.** Supabase 기본 발송은 프로젝트 팀의 이메일만 지원하므로 관리자 가입 성공만으로 외부 회원 가입을 검증할 수 없습니다. [공식 안내](https://supabase.com/docs/guides/auth/auth-smtp)
5. npm ci, npm test, npm run build로 검증합니다. npm run dev로 개발 서버를 엽니다.
6. Vercel Root Directory는 instagram-localizer입니다. Production·Preview에 VITE_SUPABASE_URL과 VITE_SUPABASE_PUBLISHABLE_KEY를 추가합니다. 서버는 동일한 값을 사용할 수 있습니다. 다른 환경에서는 SUPABASE_URL과 SUPABASE_PUBLISHABLE_KEY를 서버에 설정합니다.
7. 먼저 관리자 이메일 인증과 로그인, 다른 이메일의 가입 → 대기 → 승인 흐름을 확인합니다. 외부 AI 실사용은 본인의 키로 별도 확인합니다.

.env.local·node_modules·dist는 저장소에 올리지 않습니다. 환경변수 변경 후에는 새로 배포해야 합니다. 미리보기 주소에서 인증 링크를 사용할 때는 그 정확한 주소를 Supabase Redirect URLs에 추가합니다.

## 검증

npm test는 실제 PostgreSQL 호환 엔진에서 회원 승인·권한 상승 차단·일일 한도·정지·점검·관리 기록을 검사하고, 회원별 로컬 저장 분리, 실패 재시도, 이미지 중계 보호, 영상 자료 ZIP 구성을 검사합니다. 외부 AI API를 호출하지 않으므로 테스트에 키나 사용료가 필요하지 않습니다.
