# 🌏 인스타 현지화 스튜디오

해외에서 인기 있는 인스타그램 게시물을 **10개 나라** 버전으로 다시 만들어 주는 도구예요.

| 지역 | 나라 (언어) |
|---|---|
| 아시아 | 🇰🇷 한국 · 🇯🇵 일본 · 🇹🇼 대만(중국어 번체) · 🇮🇩 인도네시아 |
| 아메리카 | 🇺🇸 미국(영어) · 🇲🇽 멕시코·중남미(스페인어) · 🇧🇷 브라질(포르투갈어) |
| 유럽 | 🇪🇸 스페인 · 🇩🇪 독일 · 🇫🇷 프랑스 |

나라 버튼 아래에 💰(수익에 유리) / 👀(조회수에 유리) 표시가 있어요. 나라를 많이 고를수록 AI 비용과 시간이 늘어나요.

원본 이미지를 올리고 버튼을 한 번 누르면, 아래 순서로 알아서 진행돼요.

1. **분석**: AI가 이미지 속 글자, 폰트 느낌, 글자 크기·색, 배경, 배치, 그리고 **왜 떡상했는지**를 분석해요.
2. **현지화**: 이미지 속 글자를 그대로 번역하지 않고, 그 나라 크리에이터가 쓴 것처럼 자연스럽게 다시 써요. 첫 장 제목 후보 5개와 올리기 좋은 시간도 같이 만들어 줘요.
3. **설명글(캡션) 새로 쓰기** — 인스타 알고리즘(체류 시간 · 저장 · DM 공유)에 맞춘 5구역 구조
   - 원본 설명글의 **내용과 취지는 그대로** 두고, **문장 표현만 완전히 새로** 써요. 직역하지 않아서 원문 문장을 베끼지 않아요.
   - 원본에 없는 내용은 **지어내지 않아요**. "✅ 원본 내용 대조표"에서 요점이 빠지거나 추가된 게 없는지 직접 확인할 수 있어요.
   - 5구역 구조
     1. **첫 줄 훅 + 검색 키워드**: 인스타 AI가 해시태그보다 설명글을 먼저 읽고 주제를 분류해서, 첫 줄에 검색 키워드를 넣어요.
     2. **번호 본문**: 핵심을 1·2·3 번호로 정리해서 끝까지 읽게(체류 시간) 만들어요.
     3. **📌 한눈에 보기 요약**: 저장하고 싶게 만드는 요약 블록이에요.
     4. **✈️ DM 공유 CTA**: "○○한 친구가 떠오르면 DM으로 보내주세요"처럼 사람을 콕 집어요.
     5. **💬 댓글 CTA**: 쉽게 답할 수 있는 질문이에요. **댓글 → DM 자료**를 설정했다면 "댓글에 '키워드' 남기면 자료를 DM으로" 문구가 들어가요.
   - 맨 끝에 **카테고리 분류용 해시태그 3~5개**가 붙어요.
   - 사진마다 **대체 텍스트(Alt Text)** 도 만들어 줘요. 올리기 직전 **고급 설정 → 접근성 → 대체 텍스트 작성**에 붙여넣으세요.
   - 마음에 안 들면 **🔄 다른 표현으로 다시 쓰기**를 누르세요. CTA는 후보 문구를 눌러 바꿔 끼울 수 있어요.
   - 최종 설명글 순서: **훅 → 번호 본문 → 📌 요약 → ✈️ DM 공유 → 💬 댓글 → 출처 → 해시태그 3~5개**
   - ⚠️ **댓글 → DM 자동화**(📥 원본 넣기 화면의 💬 칸)는 보낼 자료가 실제로 있고, 그 키워드로 DM 자동 응답(인스타 자동 응답 · ManyChat 등)을 설정할 때만 쓰세요.
4. **이미지 생성**: 원본의 구도·색감·분위기만 참고해서, **글자 없는 새 이미지**를 AI가 그려요.
5. **글자 입히기**: 번역한 글을 진짜 폰트로 이미지 위에 올려요. AI가 글자를 직접 그리면 깨지기 쉬워서, 글자는 코드가 넣어요.
6. **다운로드**: 1080px PNG 여러 장과 캡션을 ZIP 파일 하나로 받아요.

영상(릴스)을 올리면 **번역된 자막 파일(.srt)**과 **AI 영상 도구용 장면 설명**도 만들어 줘요.

## 🧒 처음 시작하기 (딱 3단계)

### 1단계. Gemini API 키 받기 (5분)

API 키는 AI를 쓰기 위한 **비밀번호** 같은 거예요.

1. [aistudio.google.com/apikey](https://aistudio.google.com/apikey)에 들어가서 구글 계정으로 로그인해요.
2. **"Create API key"(API 키 만들기)** 파란 버튼을 눌러요.
3. `AIza...`로 시작하는 긴 글자가 나오면 **복사**해 두세요.
4. ⚠️ **이미지를 만들려면 결제 등록이 필요해요.** 같은 화면의 **"Set up billing"(결제 설정)**에서 카드를 등록하세요.
   - 비용은 대략 게시물 1개 × 3개 나라에 수백 원~천 원 정도예요. 모델과 장수에 따라 달라요.
   - 걱정되면 Google Cloud 결제 화면에서 **예산 알림**(예: 월 1만 원)을 걸어 두세요.

> 🔒 API 키는 절대 다른 사람에게 보여주거나 인터넷에 올리지 마세요.
> 이 앱은 키를 **내 브라우저에만** 저장해요.

### 2단계. 앱을 인터넷에 올리기 (Vercel · 무료 · 10분)

한 번만 해 두면 휴대폰이든 컴퓨터든 주소만 열어서 쓸 수 있어요.

1. [vercel.com](https://vercel.com)에 들어가서 **"Continue with GitHub"**로 가입해요.
2. **"Add New… → Project"**를 눌러요.
3. 목록에서 **`youtube-finder`** 저장소 옆의 **Import**를 눌러요.
4. **Root Directory** 옆의 **Edit**을 누르고 **`instagram-localizer`** 폴더를 골라요. ← 제일 중요해요!
5. **Deploy** 버튼을 눌러요.
6. 1~2분 뒤 🎉 화면이 나오면 주소(예: `https://instagram-localizer-xxx.vercel.app`)를 즐겨찾기 해 두세요.

> 💡 Vercel이 저장소를 못 찾으면 **"Adjust GitHub App Permissions"**를 눌러 `youtube-finder` 접근을 허용해 주세요.

### 3단계. 사용하기

1. 앱 주소를 열면 ⚙️ 설정 창이 떠요. 1단계에서 복사한 **API 키를 붙여넣고 저장**해요.
2. 원본 인스타 게시물을 준비해요.
   - **이미지**: 캐러셀의 각 장을 저장해요. PC라면 이미지를 우클릭해서 저장하거나 캡처해도 돼요.
   - **캡션(게시글)**: 복사해 둬요.
   - **원작자 계정**: `@아이디`를 적어 두세요. 캡션 끝에 출처로 들어가요.
3. 앱에서 **① 정보 입력 → ② 이미지를 순서대로 올리기 → ③ 나라 고르기 → ④ 이미지 방식 고르기**를 하고 **✨ 버튼**을 눌러요.
4. 1~3분 기다리면 **🎨 2. 결과 편집** 탭에 나라별 결과가 나와요. 언제든 위쪽 **📥 1. 원본 넣기** 탭을 눌러 첫 화면으로 돌아갈 수 있어요. 만든 결과는 그대로 남아 있어요.
5. 오른쪽 편집 칸에서 글자, 폰트, 크기, 색, 위치를 다듬어요. 미리보기에 바로 반영돼요.
6. **⬇️ 전체 다운로드(ZIP)**를 누르고, 휴대폰으로 옮겨서 인스타에 올리면 끝이에요.

## 📦 게시물 여러 개 한 번에 만들기 (최대 5개)

**📥 1. 원본 넣기** 화면 맨 위에 도구 두 개가 있어요.
- **🔗 링크 여러 개 한 번에 넣기**
  - 인스타 링크를 한 줄에 하나씩(최대 5개) 붙여넣고 버튼을 누르면, 링크마다 게시물 칸이 생겨요.
  - Apify를 켜 두면 사진·설명글까지 자동으로 채워져요.
- **🖼️ 사진 여러 장 → 각각 다른 게시물로**
  - 사진을 여러 장 고르면 1장씩 따로 게시물 칸에 들어가요.
  - 한 게시물에 여러 장(캐러셀)을 넣으려면, 그 게시물 칸에 직접 올려 주세요.

그 외 사용법
- **+ 게시물 추가**로 칸을 직접 늘릴 수도 있어요.
- 나라 · 이미지 설정은 **모든 게시물에 똑같이** 적용돼요.
- **✨ 게시물 N개 한 번에 만들기**를 누르면 **하나씩 차례로** 만들어요.
- **🎨 2. 결과 편집** 화면 위쪽의 **게시물 1 · 2 · 3…** 버튼으로 게시물을 골라 편집해요. 앞 게시물을 편집하는 동안 뒤 게시물이 만들어져요.
- **⬇️ 게시물 N개 전체 다운로드** 를 누르면 모든 게시물·나라를 ZIP 하나로 받아요. 안에는 `post-01/KR/…` 처럼 폴더가 나뉘어 있어요.
- 실패한 게시물은 **🔄 이 게시물 다시 만들기** 로 그것만 다시 만들 수 있어요.

## 🔗 (선택) 인스타 링크로 사진 자동 가져오기 — Apify

**안 써도 돼요.** 끄면 지금처럼 사진을 직접 올리면 돼요. 쓰고 싶을 때만 아래처럼 켜세요.

1. [apify.com](https://apify.com)에 들어가서 **Sign up**(가입)을 눌러요. 구글 계정으로 가입하면 편해요.
2. 가입 후 [console.apify.com/settings/integrations](https://console.apify.com/settings/integrations)에 들어가요.
3. **Personal API tokens** 에 있는 토큰 옆의 **복사 버튼(📋)** 을 눌러요. `apify_api_`로 시작해요.
4. 앱의 **⚙️ 설정** → **"🔗 인스타 링크로 자동 가져오기 (Apify)"** 를 체크하고, 토큰을 붙여넣고 **저장**해요.
5. 이제 게시물 칸의 링크 옆에 **🔗 가져오기** 버튼이 생겨요.

알아두실 점
- Apify는 **쓴 만큼 요금**이 나가요. 무료 크레딧이 있으니, 사용량은 Apify 사이트에서 확인하세요.
- **비공개 계정·삭제된 게시물**은 가져올 수 없어요.
- **릴스 영상 파일**은 커서 자동으로 못 가져와요.
  - 표지 사진과 설명글은 가져와요.
  - 영상까지 분석하려면, 안내에 나오는 링크로 영상을 저장해서 직접 올려 주세요.
- 인스타 입장에서는 허락받지 않은 자동 수집이라 회색지대예요. 가져온 사진은 **참고용**으로만 쓰고, 앱의 "AI로 새로 그리기"를 쓰세요.
- 끄고 싶으면 ⚙️ 설정에서 체크를 풀면 돼요.

## 🎯 떡상 확률을 높이는 사용 팁

- **첫 장이 90%예요.** "첫 장 제목 다른 버전"에서 [적용]을 눌러 여러 개를 비교해 보세요.
- **글자가 사진에 묻히면** 🌫️ **그라데이션**을 켜세요.
  - 사진 배경이면 처음부터 아래쪽에 켜져 있어요.
  - **빠른 설정**(은은하게 · 보통 · 진하게)으로 고르고, 위치(아래 · 위 · 위+아래), 색, 높이, 진하기, 부드러움을 조절할 수 있어요.
  - **"모든 장에 똑같이 적용"** 버튼을 누르면 캐러셀 전체가 통일돼요.
  - 사진 전체를 어둡게 하고 싶으면 **"어둡게"** 슬라이더를 쓰세요.
- **줄마다 글자색 바꾸기**: 글자 칸에서 Enter로 줄을 나누고 **🌈 줄마다 다른 색 쓰기**를 켜면, 줄마다 색을 고를 수 있어요.
  - 원본이 줄마다 색이 다르면 AI가 알아서 맞춰 줘요.
- **이미지가 마음에 안 들면** 이미지 설명을 고친 뒤 **🔄 다시 만들기**를 누르세요. 영어로 쓰면 더 정확해요.
- **설명글 첫 줄**이 "더 보기" 전에 보이는 유일한 글이에요. 가장 궁금하게 만드세요.
- **해시태그는 3개면 충분해요.** 많이 붙이면 스팸처럼 보여서 오히려 손해예요. 👀 최종 설명글 미리보기를 그대로 복사해서 붙여넣으세요.
- **"올리기 좋은 시간"**에 맞춰 올리고, 올린 뒤 30분 안에 달리는 댓글에는 꼭 답글을 다세요.
- **나라별로 계정을 따로** 운영하세요. 처음엔 1~2개 나라로 시작해서, 반응이 좋은 나라에 집중하는 걸 추천해요. 한 계정에 여러 언어를 섞으면 알고리즘이 헷갈려요.
- 고르는 원본은 **저장·공유가 많은 정보형**(팁, 리스트, 비교)이 번역해도 잘 떠요.

## 💾 자동 저장 — 창이 닫혀도 이어서 작업

작업 내용은 **자동으로 저장**돼요. 입력한 원본, 만든 결과, 직접 고친 글자·색·그라데이션 등이 모두 들어가요.
- 창을 닫거나, 새로고침하거나, 휴대폰에서 다른 앱으로 나갔다 와도 **그대로 이어서** 할 수 있어요.
- 화면 오른쪽 위에 **💾 자동 저장됨 (시각)** 이 보이면 저장된 거예요.
- 앱을 다시 열면 "💾 지난번 작업을 그대로 불러왔어요" 안내가 나와요.
- **만드는 도중에 창이 닫히면** 그 부분은 멈춰요. 이렇게 이어서 하세요.
  - 결과가 아직 없으면 → 결과 편집 화면에서 **🔄 이 게시물 다시 만들기**
  - 배경만 덜 만들어졌으면 → **🎨 빈 배경 N장 AI로 만들기**
- 저장은 **지금 쓰는 기기·브라우저에만** 돼요. 휴대폰에서 한 작업은 PC에서 보이지 않아요.
- 개인정보 보호(시크릿) 모드에서는 자동 저장이 안 될 수 있어요.
- 다 쓴 작업을 지우려면 **처음부터** 버튼을 누르세요.

## 🛡️ 저작권 안전 점검

결과 편집 화면 아래쪽의 **🛡️ 저작권 안전 점검**에서, 원본과 새 결과물이 얼마나 비슷한지 **퍼센트(%)와 ✅ / ⚠️ / ❌ 표시**로 보여줘요.

| 점검 항목 | 무엇을 비교하나요 |
|---|---|
| 🖼️ 사진 (장마다) | 원본 사진 ↔ 새 사진의 구도 · 밝기 흐름 · 색 |
| 📝 설명글 | 원본 문구 ↔ 새 문구: 글자가 그대로 겹치는지, 직역에 가까운지 |
| 🔤 사진 속 글자 | 원본 글자 ↔ 새 글자 |
| 🏷️ 출처 표기 | 원작자 표기가 들어갔는지 |

- **무료 점검 (자동)**: 내 컴퓨터에서 바로 계산해요. 결과를 고치면 자동으로 다시 계산해요.
- **🤖 AI 정밀 점검 (버튼)**: Gemini가 원본과 새 결과물을 나란히 보고 판단해요. 요금이 조금 들어요.
  - 다른 언어로 **직역만 했는지** 알아내요.
  - 원문을 거의 그대로 옮긴 문장을 알려 줘요.
  - **같은 실제 인물**, **워터마크·로고**가 들어갔는지 찾아요.
- 유사도 **35% 이하 ✅ 안전 · 60% 이하 ⚠️ 주의 · 그 이상 ❌ 위험**
- 맨 위의 **독창성 점수**는 100에서 평균 유사도를 뺀 값이에요. **❌ 항목이 하나라도 있으면 전체도 ❌** 로 표시돼요.
- ⚠️ 이 점수는 **참고용 자동 지표**예요. 저작권 침해 여부를 법적으로 판단하지는 못해요.

## 🛠 (선택) 내 컴퓨터에서 실행하기

개발자가 아니면 건너뛰어도 돼요. 위의 Vercel 방법으로 충분해요.

1. [nodejs.org](https://nodejs.org)에서 **LTS** 버전을 설치해요.
2. 터미널(명령 프롬프트)에서:
   ```bash
   cd instagram-localizer
   npm install
   npm run dev
   ```
3. 화면에 나오는 `http://localhost:5173` 주소를 브라우저에서 열어요.

## 📦 구성

| 파일 | 하는 일 |
|---|---|
| `src/lib/gemini.ts` | Gemini AI 연결 (분석 · 현지화 · 이미지 생성) |
| `src/lib/apify.ts` | 인스타 링크로 게시물 가져오기 (Apify, 선택) |
| `api/image.ts`, `server/imageProxy.ts` | 인스타 사진을 대신 내려받아 주는 작은 서버 부품 (인스타 사진 주소만 허용) |
| `src/lib/render.ts` | 이미지 위에 글자를 그리는 엔진 (자동 줄바꿈 · 크기 맞춤 · 일본어 줄바꿈 규칙) |
| `src/lib/countries.ts` | 나라별 말투 규칙과 폰트 목록 (모두 상업용 무료 폰트) |
| `src/components/` | 화면 (업로드 · 편집기 · 설정) |

**앞으로 붙일 수 있는 기능:** AI 영상 생성(Veo), 나라 추가(베트남 · 태국 · 아랍권 등).
