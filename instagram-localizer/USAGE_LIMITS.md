# 사용 한도 안내 (2026-10-23)

| 표시 / 단계 | 한도 주체 | 확인·해결 |
| --- | --- | --- |
| 오늘 앱 사용 한도 | 앱 회원별 일일 요청 수 | 관리자 → 회원별 한도. 기존 허용 범위 0~10,000. 한국 시간 자정에 새 날짜 계산 |
| Google API 사용량 한도 / Gemini 생성 한도 | Google 프로젝트·선택 모델 | AI Studio 사용량/결제에서 RPM·TPM·RPD·이미지 요청량·예산 확인. 일시 속도 제한은 요청 간격을 두고 재시도, 지속 한도는 공식 증액 신청 |
| Apify 크레딧·사용 한도 | 인스타 링크 조회 서비스 | Apify Billing에서 요금제·잔여 크레딧·사용 상한 확인 |
| Apify 요청 속도·동시 실행 | Apify 실행 제한 | 진행 중인 조회를 기다리고 나중에 다시 시도 |

앱 일일 횟수는 게시물 개수가 아니라 가져오기·분석·번역·사진 생성·영상 업로드 요청 시도를 함께 셉니다. 외부 서비스가 실패한 시도도 포함합니다. 키 연결 확인과 로컬 편집/PNG 내보내기는 이 예약을 하지 않습니다. 생성 단계에서는 Apify를 호출하지 않습니다. 정확한 계정 제한 원인은 해당 오류 문구와 서비스 대시보드로 확인해야 합니다.

## 무제한 여부

- Gemini와 Apify의 무료·무제한 사용은 보장할 수 없습니다. 유료 플랜도 속도·예산·모델 등의 제한이 존재합니다. 앱이 서비스 한도를 해제할 수 없습니다.
- Gemini 키 5개를 같은 프로젝트에서 만들면 한도를 공유합니다. 이 앱은 사용할 키를 직접 선택하며, 제한 회피를 위해 자동으로 키를 돌려 쓰지 않습니다.
- Google은 요금제/사용 이력에 따라 상위 한도와 증액 신청 경로를 제공합니다. Apify도 유료 요금제와 사용 상한 변경을 제공합니다. 결제·증액은 계정 소유자가 직접 결정합니다.
- 권한 있는 사진을 직접 올리고 AI 없이 직접 편집하면 Apify·Gemini 호출 비용/쿼터를 사용하지 않습니다. 기기의 저장 공간·처리 능력 제한은 남습니다. 이것은 새로운 AI 사진 생성과는 다릅니다.
- 새 AI 사진 요청을 줄이려면 자동 배경 생성 끄기, 기존 사진 재사용, 나라별 배경 따로 만들기 끄기를 사용하세요. 로컬 이미지 생성 모델은 별도 GPU·모델·구현이 필요하며 이번 버전에 추가하지 않았습니다.
- 선택 가져오기는 먼저 Apify 게시물 조회 1회와 최대 20장 미리보기를 준비합니다. 선택/취소로 이미 발생한 조회 비용이 사라지지 않습니다. 일부 사진만 선택한 경우 입력에 들어가는 장수와 이후 생성 요청 수를 줄일 수 있습니다.
