# 🎬 틀복사 스튜디오 (CapCut Template Cloner)

> 떡상한 유튜브 영상·채널의 **"고정 틀(포맷)"**을 자동으로 뜯어서,
> **캡컷에서 바로 여는 프로젝트 파일**과 **비슷하지만 다른 변형 3~5개**를 만들어 주는 앱.

## 🚀 지금 써 보기 (1단계 MVP)

1. 이 폴더의 **`틀복사스튜디오.html`** 을 더블클릭해요. (크롬이나 엣지로 열려요. 설치할 것 없음)
2. 같은 영상(또는 같은 채널의 여러 영상)의 **스크린샷 3~5장**을 올려요. 장면이 서로 다른 순간이어야 해요.
   - 채널의 여러 영상을 올리면: 영상마다 바뀌는 글자 = **제목 자리**, 늘 같은 것 = **로고 자리**로 찾아요.
   - 플레이어 화면 그대로 캡처해도 돼요. 맨 위 버튼·채널명·구분선은 자동으로 빼요.
3. 자동으로 찾은 박스·제목·자막·로고 자리를 확인하고, 틀린 곳은 드래그로 고쳐요. 💧로 원본 색을 찍을 수 있어요.
4. **"💻 캡컷 PC 초안 받기"** → 받은 zip을 캡컷 초안 폴더에 옮겨서 **압축 풀기** → 캡컷을 켜면 목록에 보여요.
   - 초안 폴더: 파일 탐색기 주소창에 `%LOCALAPPDATA%\CapCut\User Data\Projects\com.lveditor.draft` 입력
5. 모바일 캡컷이면 **"📱 틀 팩 받기"** (투명 PNG 틀 + 스타일 카드)
6. 맨 아래 **"⑤ 비슷한 틀 5개"** 에서 변형(원본·컬러·미니멀·임팩트·위아래 반전)을 골라 한 번에 받을 수 있어요.
   컬러 스왑은 내 브랜드 색으로 맞출 수 있고, 모든 변형은 글자 대비 4.5:1 이상·쇼츠 하단 UI 피하기 규칙을 자동으로 지켜요.

> 🔒 모든 분석은 내 컴퓨터 브라우저 안에서만 해요. 스크린샷이 서버로 올라가지 않아요.

### 개발자용
```bash
npm install
npm run dev            # 개발 서버
npm test               # 분석·캡컷 초안 테스트
npm run build:single   # 틀복사스튜디오.html 다시 만들기 (코드를 고친 뒤 꼭 실행)
```
| 폴더 | 역할 |
|---|---|
| `src/analyze/` | 고정 영역 찾기(`staticMask`), 박스·제목·로고 분류(`detect`), 자막 줄 찾기(`captions`), 글자 색·크기·테두리 측정(`measureText`) |
| `src/capcut/` | TemplateSpec → 캡컷 초안 JSON (`draft.ts`) + 0단계에서 캡컷 9.0으로 열린 초안의 골든 파일 |
| `src/export/` | 캔버스 그리기(`render`), zip 묶기(`packs`) |
| `src/variations/` | 변형 5종 + 지켜야 할 규칙(대비·자막 안전 영역) |
| `src/ui/` | 화면 (틀 편집기, 레이어 패널, 받기) |
| `src/lib/capcutMath.ts` | 좌표·크기 환산 공식 (`phase0/spec_to_capcut.py`와 같은 공식) |

## 한 줄 요약

```
유튜브 URL / 채널 URL / 스크린샷
        │
        ▼
 ① 틀 분석 ──► TemplateSpec(JSON) ──► ② 캡컷 초안 폴더(.zip)
        │                          ├─► ③ 투명 PNG 오버레이 + 자막 스타일(.srt/.ass)
        │                          └─► ④ 변형 3~5개 (각각 ②③ 세트)
        ▼
 "왜 이 틀이 먹히는지" 리포트
```

## 핵심 결정 5가지

1. **분석은 "AI + 픽셀 계산" 반반.** AI(Gemini)는 *"여기가 제목 박스, 여기가 로고"* 같은 **의미**를 맡고,
   색 코드·박스 크기·자막 위치 같은 **숫자**는 코드가 프레임 픽셀을 직접 재요. AI가 눈대중으로 뽑은 숫자는 틀려요.
2. **"고정 틀" = 여러 프레임에서 안 변하는 부분.** 영상 여러 장면(채널이면 여러 영상)을 겹쳐 보고 픽셀이 그대로인 영역을 틀로 판정해요.
3. **모든 결과는 TemplateSpec 하나로 모아요.** 캡컷 파일, PNG, 미리보기, 변형 모두 이 JSON에서 만들어져요.
   캡컷 포맷이 바뀌어도 내보내기 모듈만 고치면 돼요.
4. **캡컷 파일은 두 가지로 줘요.**
   - 💻 **PC 캡컷용 초안 폴더** — 열면 박스·자막·로고 자리가 이미 깔려 있음 (핵심 기능, 비공식 포맷이라 위험요소 있음)
   - 📱 **어디서나 되는 "틀 팩"** — 투명 PNG 오버레이 + 폰트 + 스타일 카드 (모바일 캡컷에서도 사용 가능, 안전한 대안)
5. **"복제"가 아니라 "구조 복제".** 레이아웃·비율·자막 규칙은 가져오고, **로고·캐릭터·고유 그래픽은 절대 복사하지 않고 내 것으로 교체**해요.

## 만드는 순서 (요약)

| 단계 | 기간 | 끝나면 되는 것 |
|---|---|---|
| **0. 캡컷 검증** ✅ 완료 (캡컷 9.0 전부 통과) | 3~5일 | 코드로 만든 초안이 **내 캡컷 버전**에서 열리는지 확인 (가장 먼저! 안 되면 전체 방향 수정) → [검증 키트](./phase0/README.md) |
| **1. MVP** ✅ 캡컷 9.0에서 열림 확인, 실제 채널 스크린샷으로 분석 보정 | 2~3주 | 스크린샷 3~5장 올리면 → TemplateSpec + PNG 틀 팩 + 미리보기 |
| **2. 캡컷 내보내기** ✅ 1단계에 합침 (0단계 T4 통과 덕분) | 1~2주 | 캡컷 PC 초안 폴더 .zip 다운로드 |
| **3. URL 분석 + 변형** 🔄 변형 5종 ✅ / URL 분석 남음 | 2주 | 유튜브 URL만 넣어도 분석, 변형 3~5개 자동 생성 |
| **4. 채널 분석** | 1~2주 | 채널 URL → 떡상 영상 골라서 "채널 공통 틀" 추출 (기존 youtube-finder 검색 기능 재사용) |

자세한 내용은 [PLAN.md](./PLAN.md)를 보세요.
