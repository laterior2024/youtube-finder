# 🛒 쇼핑쇼츠 파인더 (v1.0)

유튜브에서 **쇼핑 영상(숏폼 · 롱폼)만** 골라 찾고, 그 영상이 **지금 뜨고 있는지** 점수로 알려주는 앱이에요.

> 버전은 앱 화면 제목 옆(예: **v1.0**)에 보여요. 누르면 버전별로 바뀐 점을 볼 수 있어요.

---

## 🤔 어떻게 "쇼핑 영상만" 골라내나요?

유튜브에는 **"쇼핑" 카테고리가 없어요.** 쇼핑 영상은 '노하우/스타일', '인물/블로그' 같은 곳에 섞여 있어요.
그래서 이 앱은 **2번 거르는 방법**을 써요.

### 1번 거르기 — 쇼핑 말로 검색하기
"내돈내산 · 추천템 · 꿀템 · 쿠팡 추천 · 언박싱 · 하울 · 다이소 추천 …" 같은 **쇼핑 영상에 자주 나오는 말**로 유튜브를 검색해요.
주제(살림 · 주방 · 뷰티 · 전자기기 · 패션 · 알리/테무 · 캠핑 · 육아)마다 말 묶음이 따로 있어요.

### 2번 거르기 — 영상마다 "쇼핑 점수" 매기기
검색에 걸린 영상을 **하나하나 열어 보고** 사람이 판단하듯 단서를 찾아 점수를 더해요.

| 단서 | 점수 |
|---|---|
| 🔗 설명란에 쿠팡 · 네이버 스마트스토어 · 알리 · 테무 · 아마존 · 올리브영 등 **쇼핑 링크** | +40 |
| 📢 "쿠팡 파트너스 활동의 일환으로 … 수수료를 제공받습니다" 같은 **수수료 문구** | +40 |
| 💰 유튜브 **"유료 광고 포함"** 표시 / 협찬 문구 | +20 ~ 30 |
| 🏷️ 제목 · 태그에 추천템 · 내돈내산 · 언박싱 · 하울 · 최저가 … | 최대 +45 |
| 🛍️ 설명란에 "구매 링크", "할인 코드" 같은 말 | +15 |
| 🚫 음악 · 게임 · 뉴스 분야, 뮤비 · 직캠 같은 말 | −20 ~ 30 |

- **50점 이상 = 쇼핑 확실** · **30점 이상 = 쇼핑 같음** · **15점 이상 = 애매함** · 그 아래 = 쇼핑 아님
- 결과 화면의 **쇼핑 판별 강도**로 고를 수 있어요.
  - **엄격**: 쇼핑 확실만 (링크 · 수수료 문구가 있는 영상)
  - **보통** (추천): 쇼핑 확실 + 쇼핑 같음
  - **느슨**: 애매한 것까지
- 카드 아래 **🛒 쇼핑 확실 ○○점**을 누르면 **왜 쇼핑 영상으로 봤는지** 근거가 나와요.

### 📱 숏폼 / 🎬 롱폼 나누기
유튜브 쇼츠는 **3분까지** 올릴 수 있어요. 그래서 **3분 이하 = 숏폼**, 넘으면 **롱폼**으로 나눠요.

## 🚀 "지금 뜨고 있다"는 어떻게 아나요? — 떡상 점수 (0~100점)

| 지표 | 뜻 | 🔥 표시 기준 | 비중 |
|---|---|---|---|
| ⚡ **하루 평균 조회수** | 올린 뒤 하루에 몇 번씩 보였나 | 하루 1만 회 이상 | 35% |
| 📊 **채널 평소 대비** | 이 채널 다른 영상들(최근 20개)의 가운데 조회수보다 몇 배인가 | 3배 이상 | 25% |
| 👥 **구독자 대비** | 조회수가 구독자 수의 몇 배인가 → 구독자 밖으로 퍼지는 중 | 3배 이상 | 20% |
| 🆕 **신선도** | 최근에 올린 영상일수록 높아요 | – | 10% |
| ❤️ **반응률** | (좋아요 + 댓글) ÷ 조회수 | 5% 이상 | 10% |

- **75점↑ 🚀 지금 떡상 중** · **55점↑ 🔥 뜨는 중** · **35점↑ 📈 괜찮음** · 그 아래 😐 평범
- **⏱️ 지난 확인 후**: 같은 영상을 30분 넘게 지나서 다시 검색하면, 그 사이 **시간당 몇 회씩 늘었는지** 보여줘요.
  "지금 이 순간 오르고 있나?"를 가장 정확히 알려주는 숫자예요. **아침 · 저녁으로 한 번씩** 검색해 보세요.
- 💡 **꿀팁**: 구독자는 적은데(예: 1만) 조회수가 큰(예: 50만) 영상 = **구독자 대비 50배**. 이런 영상이 "상품 덕분에 뜬" 영상일 가능성이 높아요. 정렬을 **👥 구독자 대비 순**으로 바꿔 보세요.

## 🧒 처음 시작하기 (딱 3단계)

### 1단계. 유튜브 API 키 받기 (5분 · 무료 · 카드 등록 필요 없음)

API 키는 유튜브 정보를 받아오기 위한 **비밀번호** 같은 거예요.

1. [구글 클라우드 새 프로젝트 만들기](https://console.cloud.google.com/projectcreate)에 들어가서 구글 계정으로 로그인해요.
   - 프로젝트 이름은 아무거나 써요. (예: `shopping-finder`)
   - **만들기**를 눌러요.
2. [YouTube Data API v3 페이지](https://console.cloud.google.com/apis/library/youtube.googleapis.com)에 들어가요.
   - 화면 위쪽에 방금 만든 프로젝트 이름이 보이는지 확인해요.
3. 파란 **사용**(Enable) 버튼을 눌러요.
4. [사용자 인증 정보 페이지](https://console.cloud.google.com/apis/credentials)에서 **+ 사용자 인증 정보 만들기 → API 키**를 눌러요.
5. `AIza...`로 시작하는 긴 글자가 나오면 **복사**해 두세요.

> 🔒 API 키는 다른 사람에게 보여주거나 인터넷에 올리지 마세요. 이 앱은 키를 **내 브라우저에만** 저장해요.

### 2단계. 앱을 인터넷에 올리기 (Vercel · 무료 · 10분)

한 번만 해 두면 휴대폰이든 컴퓨터든 주소만 열어서 쓸 수 있어요.

1. [vercel.com](https://vercel.com)에 들어가서 **"Continue with GitHub"**로 가입해요. (이미 가입했으면 로그인)
2. **"Add New… → Project"**를 눌러요.
3. 목록에서 **`youtube-finder`** 저장소 옆의 **Import**를 눌러요.
4. **Root Directory** 옆의 **Edit**을 누르고 **`shopping-shorts-finder`** 폴더를 골라요. ← 제일 중요해요!
5. **Deploy** 버튼을 눌러요.
6. 1~2분 뒤 🎉 화면이 나오면 주소(예: `https://shopping-shorts-finder-xxx.vercel.app`)를 즐겨찾기 해 두세요.

> 💡 인스타그램 앱을 이미 Vercel에 올렸어도, 이건 **새 프로젝트로 한 번 더** 만들어야 해요. (같은 저장소, 다른 폴더)

### 3단계. 사용하기

1. 앱 주소를 열면 ⚙️ 설정 창이 떠요. 1단계에서 복사한 **API 키를 붙여넣고 저장**해요.
2. **① 주제**를 하나 눌러요. (예: 🍳 주방) 찾고 싶은 상품이 있으면 아래 칸에 직접 써요. (예: `선풍기`)
3. **② 형태**(둘 다 / 숏폼 / 롱폼), **③ 올린 날짜**(24시간 ~ 3달), **④ 나라**를 골라요. 모르겠으면 그대로 두세요.
4. 빨간 **🔍 쇼핑 영상 찾기**를 눌러요. 10~30초 기다려요.
5. 카드 맨 위 **🚀 떡상 점수**가 높은 영상부터 보여요. 주황색으로 빛나는 🔥 숫자가 많을수록 좋아요.
6. 마음에 드는 목록은 **📥 엑셀로 받기**로 저장할 수 있어요.

## 💰 유튜브 포인트(할당량) 알아두기

유튜브는 API를 **하루 10,000포인트까지 무료**로 줘요.

| 하는 일 | 포인트 |
|---|---|
| 검색 1번 (영상 50개) | 100 ← 비싸요 |
| 영상 · 채널 정보 (50개) | 1 |
| 채널 최근 영상 확인 (채널 1곳) | 1 |

- 이 앱으로 한 번 찾으면 보통 **150 ~ 300포인트**를 써요. → **하루 30번 이상** 찾을 수 있어요.
- 검색 버튼 옆에 **이번 검색에 쓸 포인트**와 **오늘 남은 포인트**가 보여요.
- 포인트는 **한국 시간 오후 4~5시쯤** 다시 10,000으로 채워져요.
- 포인트를 다 쓰면 "오늘 쓸 수 있는 포인트를 다 썼어요"라고 나와요. 돈이 나가지는 않아요. 다음 날 다시 하면 돼요.

## ❓ 이럴 땐 이렇게

| 문제 | 해결 |
|---|---|
| "API 키가 틀렸어요" | ⚙️ 설정에서 키를 다시 복사해서 붙여넣어요. 앞뒤 빈칸이 없는지 확인해요. |
| "YouTube Data API v3가 꺼져 있어요" | 1단계의 3번(**사용** 버튼)을 해요. 누른 뒤 2~3분 기다려요. |
| 결과가 너무 적어요 | 판별 강도를 **느슨**으로, 올린 날짜를 **1달**로 늘려 보세요. 🔧 더 자세히 → **더 많이 찾기**도 켜 보세요. |
| 쇼핑 아닌 영상이 섞여요 | 판별 강도를 **엄격**으로 바꿔요. |
| 채널 평소 대비가 "-" 로 나와요 | 채널에 비교할 영상이 3개보다 적거나, 🔧 더 자세히에서 비교를 껐을 때예요. |

## ⚠️ 알아두면 좋은 한계

- 유튜브는 **"쇼핑 태그(상품 스티커)" 정보를 API로 알려주지 않아요.** 그래서 설명란 · 제목 · 태그로 판단해요. 설명란에 링크를 안 넣는 영상은 "애매함"으로 나올 수 있어요.
- 숏폼/롱폼은 **길이(3분)** 로 나눠요. 3분 이하의 가로 영상도 숏폼으로 보일 수 있어요.
- "지난 확인 후" 기록은 **지금 쓰는 브라우저에만** 저장돼요. 휴대폰과 컴퓨터는 따로 기록돼요.

## 🛠 (선택) 내 컴퓨터에서 실행하기

개발자가 아니면 건너뛰어도 돼요.

```bash
cd shopping-shorts-finder
npm install
npm run dev
```
화면에 나오는 `http://localhost:5173` 주소를 브라우저에서 열어요.
